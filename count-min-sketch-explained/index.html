TLDR: Count-Min Sketch (CMS) is a fixed-size d × w counter matrix that estimates how often any element has appeared in a stream. Insert: hash the element with each of the d hash functions to get one column per row, increment those d counters. Query: read the same d counters, return the minimum — an upper bound that is never an underestimate. With d = 7 rows and w = 2000 columns, a ~112 KB sketch delivers <1% error for hashtag frequency estimation across millions of events — versus gigabytes for exact counting. Twitter trending topics, Akamai heavy-hitter detection, and Apache Flink streaming analytics all use Count-Min Sketch.
