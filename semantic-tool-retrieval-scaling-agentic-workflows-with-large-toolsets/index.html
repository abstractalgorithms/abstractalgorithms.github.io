TLDR: Semantic Tool Retrieval is a design pattern for agentic systems to manage and intelligently select tools from a large, expanding library. It works by embedding tool descriptions and user queries into a vector space, then using similarity search to find the most relevant tools, overcoming the limitations of static tool lists and prompt stuffing.
