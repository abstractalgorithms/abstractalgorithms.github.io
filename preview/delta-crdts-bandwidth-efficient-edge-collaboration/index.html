Delta CRDTs: Bandwidth‑Efficient Edge Collaboration

TLDR: 🚀 Delta CRDTs let edge devices sync only the changes, slashing bandwidth and latency—crucial for offline‑first, low‑latency collaboration.

🏗️ The Gotcha

Edge devices (smartphones, IoT sensors, remote terminals) often have intermittent connectivity and limited uplink bandwidth. When a CRDT (Conflict‑Free Replicated Data Type) is used naively, every update pushes the entire data structure to peers. In a 10‑kB counter that grows to 1 MB after a week of edits, this becomes a nightmare: high latency, battery drain, and data caps. The question is: Can we keep the collaborative sync fast and light without sacrificing eventual consistency?

⚡️ The Solution – Delta CRDTs

Delta CRDTs store only the change (delta) that occurred, not the whole state. Each operation produces a small delta object that is merged into the local state and propagated to peers. When a peer receives a delta, it merges it into its state and can optionally send back a compressed acknowledgment. Because deltas are usually a few bytes, bandwidth usage drops dramatically, and the time to apply changes remains low.

Key properties:

  • State‑based semantics: The merge function remains the same as a full‑state CRDT, ensuring correctness.
  • Delta generation: Each operation records the minimal information needed to reconstruct the change.
  • Compaction: Periodic full snapshots can be sent to new peers or to recover from divergence.

🧩 Code Snippet – GCounter Delta CRDT (TypeScript)

type Delta = { id: string; inc: number };
type GCounter = Map<string, number>;

function deltaInc(counter: GCounter, nodeId: string, n: number): Delta {
  const current = counter.get(nodeId) ?? 0;
  counter.set(nodeId, current + n);
  return { id: nodeId, inc: n }; // delta to send
}

function mergeDelta(counter: GCounter, delta: Delta): void {
  const current = counter.get(delta.id) ?? 0;
  counter.set(delta.id, current + delta.inc); // idempotent merge
}

When a device updates its counter, it calls deltaInc to get the delta and broadcasts it. Peers run mergeDelta on receipt. The full state can be reconstructed by summing all values in the map.

📌 Takeaway

Delta CRDTs are a practical pattern for edge‑first collaborative apps: they keep network traffic minimal, preserve low‑latency updates, and maintain the strong guarantees of CRDTs. Use them whenever you need to stay responsive on bandwidth‑constrained, unreliable links.
