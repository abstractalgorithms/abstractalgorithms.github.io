Stage 1 — Vectors and Matrices: The Language of Data

  • Every piece of data a model sees — an image, a sentence, a row in a CSV — gets turned into a vector (a list of numbers) or a matrix (a grid of numbers).
    • A 28×28 pixel image becomes a vector of 784 numbers.
    • A batch of 32 images becomes a matrix of shape (32, 784).
    • The model's learned knowledge is stored as matrices called weight matrices .

Stage 2 — Derivatives and Gradients: How Models Learn

  • A model starts with random weights and makes terrible predictions.
  • Calculus is the mechanism that turns "terrible" into "good".
  • The key concept is the derivative — how much does the loss change when you nudge one weight slightly?
  • If the derivative is positive, that weight is hurting the model; decrease it.

Stage 3 — Deep Dive: Backpropagation via the Chain Rule

  • Backpropagation is the chain rule applied layer by layer.
  • If loss L depends on weight w through a chain of functions, then ∂L/∂w = (∂L/∂output) × (∂output/∂hidden) × (∂hidden/∂w).
  • Each layer multiplies its local gradient into the upstream gradient, propagating error signals back to every weight automatically.

import numpy as np

X = np.array([[0.1, 0.9], [0.8, 0.2], [0.3, 0.7], [0.7, 0.3]])
y = np.array([1, 0, 1, 0])

W = np.array([0.5, -0.5])
b = 0.0
lr = 0.1

for step in range(20):
    logit = X @ W + b                              # linear algebra
    pred = 1 / (1 + np.exp(-logit))               # probability (sigmoid)
    loss = -np.mean(y * np.log(pred + 1e-8) + (1 - y) * np.log(1 - pred + 1e-8))
    error = pred - y
    dW = X.T @ error / len(y)                     # calculus (gradient)
    db = np.mean(error)
    W -= lr * dW                                   # gradient descent update
    b -= lr * db
    if step % 5 == 0:
        print(f"Step {step}: loss={loss:.4f}")

print("Predictions:", (pred > 0.5).astype(int))

Observable outcome: What's happening mathematically: - X @ W + b — linear algebra (matrix-vector multiply) - sigmoid(logit) — probability (converts logit to 0–1 probability) - error → dW → W -= lr dW — calculus (gradient descent)
