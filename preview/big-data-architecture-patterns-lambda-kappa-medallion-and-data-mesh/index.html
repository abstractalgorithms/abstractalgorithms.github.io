Big Data Architecture Patterns: Lambda, Kappa, CDC, Medallion, and Data Mesh

Scenario context

A serious data platform is defined less by where files are stored and more by how changes enter the system, how serving layers are materialized, and who owns quality over time. Lambda, Kappa, CDC, Medallion, and Data Mesh are patterns for making those choices explicit.
