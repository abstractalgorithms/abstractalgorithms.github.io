Stage 1 — Core Building Blocks: Tokens, Vectors, and Vocabulary

  • Before a model can process language, text must be converted into numbers.
  • Tokenization splits raw text into subword pieces using algorithms like Byte-Pair Encoding — "unfathomable" might split into ["un", "fathom", "able"] .
  • Each piece gets an integer ID, and that ID maps to a learned embedding vector — a dense list of numbers capturing the token's semantic and syntactic role.
  • These vectors are what the neural network actually processes.

Stage 3 — How the Transformer Pipeline Actually Processes Text

  • A modern NLP pipeline follows these stages: Stage 1: Tokenization Text is split into subword tokens.
  • Modern tokenizers (BPE, WordPiece) handle unknown words gracefully by breaking them into known subpieces.
  • Stage 2: Embeddings + Positional Encoding Each token ID maps to a learned dense vector $\mathbf{e} \in \mathbb{R}^d$.
  • Transformers have no built-in sense of order, so a positional encoding vector is added: the model learns "token 3 comes before token 4".

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")

print(tokenizer.convert_ids_to_tokens(tokens[0].tolist()))

Stage 4 — Deep Dive: How Tokenization Shapes What a Model Can Learn

  • Tokenization is not neutral—it directly determines what the model sees.
  • Byte-pair encoding (BPE) starts with characters and merges the most frequent pairs iteratively until reaching a target vocabulary size.
  • A word like "unbelievable" might split as un , believ , able —each piece gets its own learned embedding vector.
