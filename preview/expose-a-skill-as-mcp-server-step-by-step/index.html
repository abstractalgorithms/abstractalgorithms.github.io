Stage 5 — MCP Inspector: The Debugging Tool You'll Use Every Day

  • The MCP Inspector ( mcp dev ) is the single most useful tool in the MCP development workflow.
  • It is open-source, ships with the mcp[cli] package, and runs entirely locally — no cloud account required.
  • What the Inspector UI shows: - Tools tab: Every tool your server advertises via list tools , with the full JSON Schema rendered as a human-readable form.
  • If a tool is missing here, the client will never see it.
