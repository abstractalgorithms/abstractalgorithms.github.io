TLDR: Async Python is not about true parallel multi-core execution (which is blocked by the GIL), but about cooperative multitasking. By yielding control at every I/O await boundary, a single thread can interleave thousands of waiting tasks, avoiding CPU idle time. Regular functions execute immediately; async def functions return suspended coroutines that must be driven by an event loop.
