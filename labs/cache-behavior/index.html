Cache Behavior Lab

Change hit rate and latency assumptions to see why a cache can protect an origin service and where it cannot.

The question

How do hit rate and cache/origin latency change the load and expected latency of a read path?

Assumption: The model uses steady-state assumptions: origin reads = request rate × (1 − hit rate); expected latency = cache lookup latency + (1 − hit rate) × origin latency.

Change the assumptions

What this model shows

100 origin reads per second remain after the cache.

6.0 ms expected latency follows from the current assumptions.

A 90% hit rate on 1,000 requests per second sends about 100 reads per second to the origin. With 1 ms cache lookup and 50 ms origin latency, expected latency is about 6 ms. This is a model, not a production benchmark.
