STAGE 01 · WHAT IT ISL4 · FUNDAMENTALS

What is Prim's Minimum Spanning Tree Algorithm.

Why this matters: The mechanism: understand how Prim's Minimum Spanning Tree Algorithm works from first principles.

Given a connected, undirected, weighted graph G=(V,E)G = (V, E)G=(V,E), a Minimum Spanning Tree (MST) is a subset of V−1V - 1V−1 edges connecting all vertices with no cycles and minimum total edge weight. Prim's algorithm grows the MST greedily from a root vertex: at each step, it selects the minimum-weight edge crossing the cut between visited vertices SSS and unvisited vertices V∖SV \setminus SV∖S.

Its correctness follows directly from the Cut Property: the lightest edge crossing any cut (S,V∖S)(S, V \setminus S)(S,V∖S) must belong to an MST.

Cut Property Expansion

Prim's Greedy Frontier Growth on Graph {A,B,C,D,E}

1.1. Seed Root: Mark A visited; push (2, B) and (3, C) onto the min-heap.

2.2. Pop Minimum: Pop (2, B), mark B visited on pop, and push (1, C) and (4, D).

3.3. Skip Stale: Later when stale (3, C) pops, C is already in visited so it is skipped.

Unlike Dijkstra's (which pushes dist[u] + w), Prim's pushes only the single crossing edge weight w(u, v).

When implementing Prim's with a binary min-heap (heapq / PriorityQueue), the #1 bug is marking visited[v] = True when pushing (w, v) instead of when popping—which locks in the first-seen edge rather than the minimum-weight edge.

Handles Negative Edge Weights Natively

Because Prim's compares single edge weights across a cut rather than cumulative path sums, negative edge weights work without modification (unlike Dijkstra's).

MST Is Not a Shortest-Path Tree

An MST minimizes the sum of all edge weights across the network; individual node pairs may take more hops than their Dijkstra shortest path.

import heapq

def prim_mst(n: int, adj: list[list[tuple[int, int]]]) -> int:
    visited: set[int] = set()
    heap: list[tuple[int, int]] = [(0, 0)]  # (edge_weight, vertex)
    total = 0
    while heap and len(visited) < n:
        w, u = heapq.heappop(heap)
        if u in visited:
            continue
        visited.add(u)
        total += w
        for v, edge_w in adj[u]:
            if v not in visited:
                heapq.heappush(heap, (edge_w, v))
    if len(visited) != n:
        raise ValueError("Graph is disconnected; no single spanning tree exists")
    return total
