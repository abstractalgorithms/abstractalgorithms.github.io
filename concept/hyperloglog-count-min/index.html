HyperLogLog & Count-Min
Sketch (Streaming Sketches).

HyperLogLog tracks max leading-zero runs across m registers to estimate distinct counts in ~1.5–12 KB, while Count-Min Sketch uses d hash rows x w counters to bound item frequencies in sub-megabyte RAM.

The idea to keep with you

If disk I/O or compaction stalls threaten tail latency, use HyperLogLog for COUNT(DISTINCT) and Count-Min Sketch (+ min-heap) for Top-K heavy hitters whenever O(N) HashSets or HashMaps would OOM.

TL;DR30-second simplified summary
▾

HyperLogLog estimates billion-scale distinct counts in O(2^p) fixed bytes (~12 KB at p=14 for 0.81% error) via leading-zero registers and harmonic-mean averaging, while Count-Min Sketch bounds frequencies in O(d*w) counters. Both merge across shards in O(1) network size and pair with a size-K min-heap for heavy hitters.
