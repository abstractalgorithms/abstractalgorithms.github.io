What is Free-Threaded Python (PEP 703).

Why this matters: The mechanism: understand how Free-Threaded Python (PEP 703) works from first principles.

CPython's Global Interpreter Lock (GIL) existed because Py_INCREF/Py_DECREF reference counting was not thread-safe. PEP 703 (python3.13t+) removes the GIL by introducing Biased Reference Counting (BRC), mimalloc per-thread heaps, immortal objects (PEP 683 for None/True/small ints), and per-object critical sections for list/dict/set.

Multiple OS threads can now execute Python bytecode simultaneously across CPU cores inside one shared heap.

GIL Runtime State

Free-Threaded CPython Import & GIL Fallback States

Importing a single C-extension without Py_MOD_GIL_NOT_USED silently re-enables the GIL at runtime.

STAGE 02 · WHY WE NEED ITL4 · FUNDAMENTALS

Why we need No-GIL (and why Compound Races Now Surface).

Why this matters: The problem: see what breaks without No-GIL under real concurrency or scale.

Think of Why we need No-GIL (and why Compound Races Now Surface) as the intuition layer for Python GIL-Free Concurrency, Asyncio & Coroutines: The problem: see what breaks without No-GIL under real concurrency or scale.

Previously, CPU-bound Python required multiprocessing, duplicating multi-gigabyte model weights or rule graphs across N processes and serializing payloads over IPC pipes. Under python3.13t, shared-memory threads eliminate that duplication—but code like counter += 1 or d[k] = d.get(k, 0) + 1, which accidentally relied on GIL bytecode-switch atomicity, now exhibits real lost-update data races.

import sys, threading
from concurrent.futures import ThreadPoolExecutor

# 1. Fail loudly in startup probe if any imported wheel re-enabled the GIL
if hasattr(sys, "_is_gil_enabled") and sys._is_gil_enabled():
    raise RuntimeError("GIL was re-enabled by an incompatible C extension")

_lock = threading.Lock()
shared_counts: dict[str, int] = {}

def score_chunk(items: list[str]) -> None:
    local_counts: dict[str, int] = {}
    for item in items:
        local_counts[item] = local_counts.get(item, 0) + 1
    with _lock:  # Merge once per chunk to avoid lock contention & false sharing
        for k, v in local_counts.items():
            shared_counts[k] = shared_counts.get(k, 0) + v

After · Bounded Permits + Lock-Free CAS
