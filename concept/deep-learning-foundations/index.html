What are Backpropagation, Transformers & AdamW.

Why this matters: The mechanism: understand how Backpropagation, Transformers & AdamW works from first principles.

Modern deep learning minimizes a scalar loss L(theta) over mini-batches using three coupled primitives:

  1. Backpropagation: Reverse-mode autograd applies the chain rule in reverse topological order over the computation graph (loss.backward()), reusing cached forward activations.
  2. Transformers: Replace sequential RNN recurrence with Multi-Head Self-Attention (Attention(Q,K,V) = softmax(QK^T / sqrt(d_k))V) inside Pre-RMSNorm residual blocks, saturating GPU tensor cores.
  3. AdamW: Converts noisy mini-batch gradients into bounded updates using exponential moving averages (m_t, v_t) plus decoupled weight decay.

Why Attention Memory Explodes (and How FlashAttention-2 + BF16 Fix It).

Why this matters: The problem: see what breaks without Why Attention Memory Explodes under real concurrency or scale.

Think of Why Attention Memory Explodes (and How FlashAttention-2 + BF16 Fix It) as the intuition layer for Deep Learning Foundations: Backpropagation, Transformers & Optimizers: The problem: see what breaks without Why Attention Memory Explodes under real concurrency or scale.

Standard attention materializes an [N, N] matrix in GPU HBM—at N = 16,384, batch 4, 32 heads in BF16, that single tensor consumes 68.7 GB before backward starts! FlashAttention-2 tiles Q, K, V into on-chip GPU SRAM using online log-sum-exp rescaling, cutting attention HBM memory from O(N^2) to O(N) and speeding up training 2–3x.

# Production PyTorch BF16 + FlashAttention SDPA + AdamW parameter-group setup
import torch

decay_params = [p for n, p in model.named_parameters() if p.requires_grad and p.ndim >= 2]
no_decay_params = [p for n, p in model.named_parameters() if p.requires_grad and p.ndim < 2]
optimizer = torch.optim.AdamW([
    {'params': decay_params, 'weight_decay': 0.1},
    {'params': no_decay_params, 'weight_decay': 0.0},
], lr=2e-4, betas=(0.9, 0.95))

with torch.amp.autocast('cuda', dtype=torch.bfloat16):
    loss = model(input_ids, labels=labels)  # uses SDPA FlashAttention backend
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
optimizer.step()
optimizer.zero_grad(set_to_none=True)
