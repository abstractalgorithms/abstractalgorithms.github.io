XSS & Content
Security Policy.

Cross-Site Scripting (XSS) lets attackers execute arbitrary JavaScript in a victim's browser origin; Content Security Policy (CSP Level 3) acts as defense-in-depth by restricting script execution to cryptographically random per-request nonces and Trusted Types.

THE BIG IDEA / Key takeaway · CONCEPT GUIDE

Pair context-aware output encoding and DOMPurify sanitization with a strict CSP (`script-src 'nonce-<128-bit>' 'strict-dynamic'; object-src 'none'; base-uri 'none'`) and Trusted Types to neutralize both server and DOM XSS.

01 / The idea

Foundational mechanics & core principles

A single XSS vulnerability bypasses authentication, reads localStorage/session tokens, performs authenticated API actions as the victim, and exfiltrates sensitive data. Even modern frameworks like React only protect JSX text nodes—leaving href="javascript:...", dangerouslySetInnerHTML, and third-party scripts wide open.
