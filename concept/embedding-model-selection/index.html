STAGE 01 · WHAT IT ISL4 · FUNDAMENTALS

What is an Embedding Model.

An embedding model is a transformer bi-encoder that projects variable-length text or code into a fixed-length vector v ∈ ℝ^D. Semantically similar concepts land near each other, enabling sub-20 ms Approximate Nearest Neighbor (ANN) search via HNSW or IVF-PQ.

Selecting a model balances four axes: domain recall (does it understand your jargon?), context window (max_seq_length), vector RAM footprint (N * D * bytes + ~50–100% HNSW graph overhead), and serving economics (API vs self-hosted GPU).

STAGE 02 · WHY WE NEED ITL4 · FUNDAMENTALS

Why Generic MTEB Averages Mislead (and How Hybrid + MRL Fixes Recall & RAM).

No amount of LLM prompt engineering recovers if the retriever misses the right chunk in top-K. Passing 1,500-token chunks into a 512-token model silently drops 75% of text, and dense vectors alone miss exact SKUs or statutory codes (Section 43(b), XJ-904-B).

Hybrid + Rescoring Pipeline

MRL + int8 RAM Index Paired with BM25 RRF & Cross-Encoder Rerank

MRL truncation + int8 quantization shrink HNSW RAM by 4x–12x while full-precision rescoring + BM25 RRF preserve >95% recall.

Legal RAG: 58% -> 91% Recall@10 via MRL + Hybrid

1,200-token clauses were silently truncated by all-MiniLM-L6-v2 (512-tok limit). Switching to text-embedding-3-large (8k ctx, MRL-sliced to 1024d) + BM25 RRF + bge-reranker-v2-m3 jumped Recall@10 to 91%.

Self-Hosted GPU Cutting Monthly Spend ($2,400 -> $350)

Serving BAAI/bge-base-en-v1.5 (768d) in FP16 via Text Embeddings Inference (TEI) on one L4 GPU hit 1,800 docs/sec at ~$350/mo with zero external PII egress.

STAGE 04 · HOW IT IS MANAGEDL5 · APPLIED DESIGN

How to Enforce Prefixes, MRL Normalization & Blue/Green Re-Indexing.

  1. Asymmetric Prefixes: Models like E5, BGE, and Cohere embed-v3 require query: vs passage: (or input_type='search_query')—encapsulate this in one versioned client wrapper.
  2. Re-Normalize After MRL Slicing: After truncating 3072d -> 1024d, L2-normalize (v / ||v||_2) before cosine/IP indexing.
  3. Persist Raw Chunks + embedding_model_id: Tag every collection with its model version and run blue/green index rebuilds on model upgrades.
# MRL truncation + L2 re-normalization + normalized cosine retrieval (Python)
import math
from typing import List

def truncate_and_normalize(vec: List[float], target_dim: int = 1024) -> List[float]:
    sliced = vec[:target_dim]
    norm = math.sqrt(sum(x * x for x in sliced)) or 1e-12
    return [x / norm for x in sliced]

def cosine_similarity(a: List[float], b: List[float]) -> float:
    return sum(x * y for x, y in zip(a, b))  # Exact cosine when both vectors are L2-normalized
