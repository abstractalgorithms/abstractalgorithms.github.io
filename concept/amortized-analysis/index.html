What is Amortized Analysis.

Amortized Analysis bounds the worst-case total cost T(n)T(n)T(n) of any valid sequence of nnn operations and reports T(n)/nT(n)/nT(n)/n. Unlike average-case analysis (which assumes random inputs), amortized bounds are 100% deterministic via three equivalent proof methods: Aggregate (sum total cost ÷n\div n÷n), Accounting (bank credits on cheap ops to pay for expensive ones), and Potential (c^i=ci+Φ(Di)−Φ(Di−1)\hat{c}_i = c_i + \Phi(D_i) - \Phi(D_{i-1})c^i​=ci​+Φ(Di​)−Φ(Di−1​) with Φ(Di)≥0\Phi(D_i) \ge 0Φ(Di​)≥0).

Why we need Amortized Bounds (and why naive resizing fails).

Without amortized analysis, engineers accidentally write Θ(n2)\Theta(n^2)Θ(n2) additive resizing (cap += 64), 50% shrink thrashing (push, pop at cap/2), or suffer unbounded tail latency from O(n)O(n)O(n) single-threaded hash-table rehashes.

De-Amortized Rehashing

Two-Table Incremental Rehash (Redis / Go Maps) Bounding Tail Latency

Incremental two-table rehashing spreads the O(n) copy across subsequent O(1) operations so p99 latency stays flat.

Amortized vs. Average-Case

Average-case assumes random input distributions; amortized guarantees hold for any adversarial sequence of operations.

Pre-Allocation

Calling reserve(N) or new ArrayList<>(N) when target size is known eliminates resize copies altogether.

STAGE 04 · HOW IT IS MANAGEDL5 · APPLIED DESIGN

How Resizing, Growth Factors, and De-amortization are managed.

Tune growth factors (1.5x vs 2x), shrink at size <= cap // 4, and migrate buckets incrementally on single-threaded event loops.

# Dynamic array with 2x growth & 1/4 shrink hysteresis (O(1) amortized push/pop)
class AmortizedArray:
    def __init__(self):
        self._cap = 1
        self._size = 0
        self._buf = [None] * self._cap

    def push(self, val):
        if self._size == self._cap:
            self._resize(self._cap * 2)
        self._buf[self._size] = val
        self._size += 1

    def pop(self):
        if self._size == 0:
            raise IndexError("empty")
        self._size -= 1
        val = self._buf[self._size]
        self._buf[self._size] = None
        if self._cap > 1 and self._size <= self._cap // 4:
            self._resize(self._cap // 2)
        return val

    def _resize(self, new_cap: int):
        new_buf = [None] * new_cap
        for i in range(self._size):
            new_buf[i] = self._buf[i]
        self._buf = new_buf
        self._cap = new_cap
