The idea to keep with you

If replicas diverge under asymmetric network delays, adaptive K-way salting spreads 80k QPS hot-key writes evenly across all K shards.

TL;DR30-second simplified summary
▾

Deterministic hash(key) % N routing collapses when Zipfian skew concentrates traffic on a single celebrity key. Adaptive salted sharding appends a bounded salt #0..#(K-1) only to detected hot keys, spreading write load uniformly across K shards while executing bounded O(K) parallel scatter-gather on reads.

Consistent Hashing & Virtual Nodes
Consistent hashing assigns data keys to servers in a way that limits how many keys move when servers are added or removed. This helps avoid widespread cache misses and sudden load on databases.

Engineering Decision Framework
Problem
How to implement Salted Sharding & Bounded Scatter-Gather without hitting unbounded tail latency, state divergence, or operational fragility.
Naive Solution
Use a single unpartitioned path with unbounded retries and synchronous global coordination.
Why It Fails
Global coordination serializes throughput under load, while unbounded retries amplify transient stalls into full outages.
Alternatives
Compare synchronous strict-consistency paths against bounded asynchronous replication, local caching, or partitioned ownership.
Engineering Decision
If replicas diverge under asymmetric network delays, adaptive K-way salting spreads 80k QPS hot-key writes evenly across all K shards.
Trade-Offs
Gains predictable p99 latency and fault isolation in exchange for explicit bounding, observability, and slightly higher implementation complexity.
