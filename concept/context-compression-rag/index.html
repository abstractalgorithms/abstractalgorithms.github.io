STAGE 01 · WHAT IT ISL4 · FUNDAMENTALS

What is Context Compression for RAG.

Why this matters: The mechanism: understand how Context Compression for RAG works from first principles.

Dense embedding models (using cosine similarity over 768–1536d vectors) optimize for broad semantic recall, frequently pulling 512-token chunks where only 40 tokens actually answer the user's question. Context compression sits between retrieval and generation as an information bottleneck.

It operates across two complementary axes:

  1. Coarse-grained filtering: Cross-encoder rerankers (BAAI/bge-reranker-v2-m3, Cohere Rerank) score (query, chunk) pairs jointly and discard irrelevant chunks.
  2. Fine-grained compression: Extractive sentence selection (RECOMP-Extractive), perplexity/classifier-based token pruning (LLMLingua-2), or query-focused abstractive distillation strip boilerplate tokens inside surviving chunks while preserving <doc id="..."> citation tags.

Why we need Context Compression (TTFT, Cost & Lost-in-the-Middle).

Even with 128k–1M token context windows, stuffing 25 retrieved chunks (~12,800+ tokens) into every prompt inflates Time-to-First-Token (TTFT) from 250 ms to >2,000 ms, multiplies API spend by 5–10x, and degrades answer accuracy due to the lost-in-the-middle U-shaped attention curve where models attend strongly to the first and last 10% of the prompt while ignoring middle evidence.

STAGE 04 · HOW IT IS MANAGEDL5 · APPLIED DESIGN

How to manage Citation Mapping, Negations & Ordering.

Why this matters: Operational control: configure bounds, failure handling, and safe production defaults.

Safe production compression requires four guardrails:

  1. Rerank Before Compressing: Never feed 30 noisy vector results straight into a token compressor; cross-encoder rerank first.
  2. Protect Negations & Delimiters: Pass force_tokens=['\n', '.', 'not', 'except', 'unless', 'ms', 's'] in LLMLingua-2 and bypass fenced code blocks and Markdown <table> blocks.
  3. Preserve Per-Chunk Citation IDs: Compress each chunk independently inside <doc id="..." url="..."> wrappers so inline citations survive.
  4. LongContextReorder: Place the highest-scored chunks at the beginning and end of the prompt to defeat lost-in-the-middle attention decay.

How to manage Citation Mapping, Negations & Ordering

# 2-stage RAG pipeline: Cross-Encoder Rerank + U-shaped LongContextReorder
from typing import List, Tuple

def long_context_reorder(scored_chunks: List[Tuple[float, str]]) -> List[str]:
    """Place highest-scored chunks at start and end to counter lost-in-the-middle."""
    ordered = sorted(scored_chunks, key=lambda x: x[0], reverse=True)
    left, right = [], []
    for idx, (_, chunk) in enumerate(ordered):
        (left if idx % 2 == 0 else right).append(chunk)
    return left + list(reversed(right))
