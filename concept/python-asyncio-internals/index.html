What is Python Asyncio.

Why this matters: The mechanism: understand how Python Asyncio works from first principles.

Python asyncio is a single-threaded, cooperative concurrency runtime built around an event loop (epoll / kqueue). Coroutines (async def) only yield control back to the event loop at explicit await points—keeping per-task memory in kilobytes with zero lock contention on shared single-thread structures.

Python 3.11+ asyncio.TaskGroup provides structured concurrency: if any child task raises an exception, sibling tasks are cancelled cleanly before the group exits.

Design Trade-Off

How TaskGroup, Semaphores & `to_thread` are used

Before · Unbounded Pool + Nested Locks
  • AB-BA deadlock or OOM heap
  • Blocking I/O starves event loop
  • False sharing thrashes L1 cache
After · Bounded Permits + Lock-Free CAS
  • CallerRuns / shed at capacity
  • Padded cache lines prevent bouncing
  • Structured timeouts release leaks
import asyncio, httpx

async def fetch_all_bounded(urls: list[str], max_concurrency: int = 20) -> list[int]:
    sem = asyncio.Semaphore(max_concurrency)
    results: list[int] = []

    async def fetch_one(client: httpx.AsyncClient, url: str) -> None:
        async with sem:
            async with asyncio.timeout(5.0):
                resp = await client.get(url)
                results.append(resp.status_code)

    async with httpx.AsyncClient() as client:
        async with asyncio.TaskGroup() as tg:
            for u in urls:
                tg.create_task(fetch_one(client, u))
    return results
