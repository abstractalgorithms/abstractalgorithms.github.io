STAGE 01 · WHAT IT ISL4 · FUNDAMENTALS

What is Contract Testing + Chaos Engineering.

Why this matters: The mechanism: understand how Contract Testing + Chaos Engineering works from first principles.

Contract testing (via Pact V4 and a Pact Broker) proves structural and semantic compatibility: that Consumer A's requests and Provider B's responses match agreed JSON/Protobuf schemas, headers, and status codes in isolated CI runs.

Chaos engineering (via Toxiproxy, Envoy fault filters, or Chaos Mesh) injects controlled turbulence—2,500 ms tail latency, 15% packet loss, TCP resets mid-stream, and pod kills. Unifying both means contracts explicitly model degraded error envelopes (429 Retry-After, 503 RFC 9457 application/problem+json, Idempotency-Key), and chaos experiments prove circuit breakers and retries uphold SLOs when those faults happen live.

STAGE 04 · HOW IT IS MANAGEDL5 · APPLIED DESIGN

How to manage Timeouts, Jittered Retries & Chaos Scopes.

Why this matters: Operational control: configure bounds, failure handling, and safe production defaults.

Continuous resilience follows a strict hierarchy:

  1. Timeout Hierarchy: Enforce Edge Gateway > Upstream Service > Leaf DB Query so callers never waste compute on already-abandoned requests.
  2. Idempotent Bounded Retries: Require Idempotency-Key headers in Pact POST/PATCH contracts, and pair exponential backoff with full jitter and a 20% retry budget.
  3. Scoped Blast Radius: Restrict Chaos Mesh manifests to target pod labels, set hard duration TTLs (90s–120s), and wire Prometheus alert webhooks to auto-abort.

# Production-safe bounded retry with full jitter & retry budget guard (Python)
import random, time

def execute_idempotent_retry(fn, idempotency_key: str, max_attempts: int = 4, base_delay_s: float = 0.05):
    for attempt in range(max_attempts):
        try:
            return fn(idempotency_key=idempotency_key)
        except TransientError:
            if attempt == max_attempts - 1:
                raise
            cap = base_delay_s * (2 ** attempt)
            time.sleep(random.uniform(0.0, cap))  # Full jitter prevents thundering herd
