Event-Driven Architecture & Message Streaming

Decouple microservices using distributed commit logs, message queues, and event streams.

Orientation & Intuition

Event-driven architecture replaces synchronous REST HTTP calls with asynchronous event publishing (Kafka/RabbitMQ), ensuring high throughput and fault isolation.

Key takeaway Use append-only distributed logs (Kafka) for durable replayable streams.

Core Architecture & Trade-offs

Direct HTTP microservice chains create cascading failure risks.

Key Architecture Invariants

  • Pub/Sub broadcasts events to multiple subscribers.
  • Kafka partitions guarantee sequential ordering per key.

When to Use

  • Asynchronous background processing.
  • High-throughput log analytics.

When NOT to Use

  • Simple CRUD applications.
