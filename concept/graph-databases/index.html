DATABASES & STORAGE ENGINES · STAGE 01L4 · FUNDAMENTALS

The idea & core mechanics.

A 4-hop "friends-of-friends" or "fraud ring" query in an RDBMS requires 4 self-JOINs over millions of rows, causing latency to explode exponentially. Native graph databases use index-free adjacency so traversal cost depends only on the local neighborhood size, not total graph size.

ChoiceWhat it buysWhat it costs
Good candidateSocial networks, recommendation engines, real-time fraud ring detection, and knowledge/dependency graphs (3+ hop traversals).
Good candidateSchemas where relationships carry rich properties (weights, timestamps, roles) and evolve frequently.
Think twiceHigh-volume flat event logs, time-series metrics, or global full-table analytical aggregations (use columnar/time-series stores instead).

Principle 1

Property Graph model: Nodes (vertices) with labels & key-value properties, connected by directed typed Edges (relationships) with properties.

Principle 2

Index-free adjacency: each node physically points to its incident edges in memory/disk—traversing an edge is an O(1)O(1)O(1) pointer chase rather than an O(log⁡N)O(\log N)O(logN) B-tree index lookup.

Principle 3

Query languages: Cypher (MATCH (a)-[:FOLLOWS*1..3]->(b)), Gremlin (imperative traversal), and GraphQL-over-graph.

Principle 4

Scaling challenge: partitioning arbitrary graphs across shards without cutting hot edges (min-cut partitioning) is hard; many systems keep the graph topology in distributed RAM.

Reference Implementations (Python & Java)

# 2-hop fraud/friend-of-friend BFS traversal (Python)
from collections import deque

def k_hop_neighbors(adj: dict[str, list[str]], start: str, max_hops: int = 3) -> set[str]:
    visited = {start}
    q = deque([(start, 0)])
    while q:
        node, depth = q.popleft()
        if depth == max_hops:
            continue
        for nxt in adj.get(node, []):
            if nxt not in visited:
                visited.add(nxt)
                q.append((nxt, depth + 1))
    return visited

// 2-hop / K-hop BFS traversal (Java)
public Set<String> kHopNeighbors(Map<String, List<String>> adj, String start, int maxHops) {
    Set<String> visited = new HashSet<>(List.of(start));
    Queue<String[]> q = new ArrayDeque<>();
    q.add(new String[]{start, "0"});
    while (!q.isEmpty()) {
        String[] cur = q.poll();
        int depth = Integer.parseInt(cur[1]);
        if (depth == maxHops) continue;
        for (String nxt : adj.getOrDefault(cur[0], List.of())) {
            if (visited.add(nxt)) q.add(new String[]{nxt, String.valueOf(depth + 1)});
        }
    }
    return visited;
}
