What are Counting Sort & Radix Sort.

Why this matters: The mechanism: understand how Counting Sort & Radix Sort works from first principles.

Comparison sorts (Quicksort, Mergesort, Timsort) require at least log2(n!) = Ω(n log n) comparisons. Counting Sort sidesteps comparisons by treating each integer key in [0, k) as a direct array index: tallying a frequency histogram, converting frequencies to destination offsets via an exclusive prefix sum, and scattering elements stably in O(n + k) time.

Radix Sort generalizes this to w-bit keys by slicing each key into d = ceil(w / r) digits of r bits (base b = 2^r, typically r = 8 -> 256 buckets) and running Counting Sort once per digit in O(d(n + b)) time with zero data-dependent branches.

How to handle Signed Ints, IEEE-754 Floats & L1d Sizing.

Why this matters: Operational control: configure bounds, failure handling, and safe production defaults.

1.

Radix Width (r = 8 or 11): r = 8 (256 buckets * 4B = 1 KB) fits entirely inside a 32–48 KB L1d cache. Picking r = 16 (256 KB) thrash-misses L1d and the 64-entry L1 DTLB. 2. Signed & Float Bijections: Two's-complement negatives have MSB=1 (key ^ 0x80000000 fixes signed int32).

How to handle Signed Ints, IEEE-754 Floats & L1d Sizing

# 8-bit LSD Radix Sort for signed 32-bit integers via sign-bit bijection (Python)
def radix_sort_int32(nums: list[int]) -> list[int]:
    if len(nums) < 2:
        return nums
    # Map signed int32 [-2^31, 2^31-1] -> unsigned [0, 2^32-1]
    arr = [(x & 0xFFFFFFFF) ^ 0x80000000 for x in nums]
    out = [0] * len(arr)
    for shift in (0, 8, 16, 24):
        count = [0] * 256
        for v in arr:
            count[(v >> shift) & 0xFF] += 1
        pos = 0
        for b in range(256):
            c = count[b]
            count[b] = pos
            pos += c
        for v in arr:
            b = (v >> shift) & 0xFF
            out[count[b]] = v
            count[b] += 1
        arr, out = out, arr
    return [((x ^ 0x80000000) - (1 << 32) if (x ^ 0x80000000) & 0x80000000 else (x ^ 0x80000000)) for x in arr]
