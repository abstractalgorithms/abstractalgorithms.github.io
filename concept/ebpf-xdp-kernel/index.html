eBPF & XDP
In-Kernel Packet Processing.

eBPF runs sandboxed, JIT-compiled bytecode safely inside the Linux kernel, and XDP (eXpress Data Path) hooks directly into the NIC driver RX ring before sk_buff allocation—enabling 20M+ PPS filtering per core.

The idea to keep with you

If latency budgets leave no room for synchronous retries, attach XDP at the NIC driver layer to drop or bounce packets before sk_buff allocation, using Per-CPU BPF Maps to avoid cross-core lock contention.

TL;DR30-second simplified summary
▾

eBPF compiles bounded, Verifier-proven bytecode to native machine code inside the Linux kernel. Attached at the NIC driver RX ring via XDP, programs inspect raw DMA frames before sk_buff allocation, using Per-CPU BPF maps and LPM tries to drop, hairpin-forward (XDP_TX), or redirect (AF_XDP) 20M+ PPS per core.

Zero-Copy I/O, sendfile & io_uring
