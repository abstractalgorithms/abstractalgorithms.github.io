What are Matrix Traversal Patterns.

Why this matters: The mechanism: understand how Matrix Traversal Patterns works from first principles.

A matrix traversal pattern defines the order and data structure used to visit cells in an R×CR \times CR×C grid:

  • Row-Major Sweep: for r: for c: streams contiguous 64-byte cache lines (20x–60x faster than column-major in C/Java/NumPy).
  • Multi-Source BFS: enqueues all dist = 0 sources up front to compute shortest distances in a single O(R⋅C)O(R \cdot C)O(R⋅C) wavefront.

Even when two algorithms share O(R⋅C)O(R \cdot C)O(R⋅C) asymptotic complexity, two pitfalls break production grids:

  • Call-Stack Overflow: a snake-like path on a $500 \times 500$ grid reaches recursion depth 250,000, crashing Python (RecursionError at ~1,000) or Java (StackOverflowError).
  • Cache-Line Thrashing: striding by column (grid[r][c] with r in the inner loop) misses L1/L2 hardware prefetchers on every step.

Seed the queue with every origin cell at distance 0, mark visited immediately on enqueue, and expand 4-directionally.

Component Topology

Multi-Source BFS with Mark-on-Push

from collections import deque
from typing import List

def nearest_zero_distance(grid: List[List[int]]) -> List[List[int]]:
    R, C = len(grid), len(grid[0])
    dist = [[-1] * C for _ in range(R)]
    q = deque()
    for r in range(R):
        for c in range(C):
            if grid[r][c] == 0:
                dist[r][c] = 0
                q.append((r, c))  # Mark-on-push prevents duplicate enqueues

    while q:
        r, c = q.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    return dist

Cache-Blocked Tiling & 0-1 BFS.

Why this matters: Production architecture: see how the components compose end to end under real load.

Think of Cache-Blocked Tiling & 0-1 BFS as the intuition layer for Matrix Traversal Patterns: Production architecture: see how the components compose end to end under real load.

In numerical kernels and raster pipelines, cache blocking (tiling) processes $32 \times 32$ or $64 \times 64$ sub-blocks that stay resident in L1/L2 cache during matrix transpose or stencil sweeps, avoiding DRAM bandwidth stalls.

Memory Layout

Row-Major Cache-Blocked Tiling (L1/L2 Locality)

1.1. Row-Major Sweep: Walking r outer, c inner streams sequential 64-byte cache lines 20x-60x faster than column-major.

2.2. Cache Blocking: Matrix transpose and stencil kernels iterate 32x32 sub-blocks that stay hot in L1/L2.

3.3. Flat Indexing: 1D contiguous buffers avoid pointer-chasing across rows.

Aligning traversal order with row-major memory layout eliminates DRAM cache-miss stalls.

0-1 BFS Deque Optimization

Push 0-cost edges with appendleft() and 1-cost edges with append() to solve weighted {0, 1} grids in O(R⋅C)O(R \cdot C)O(R⋅C).

Row-Major Allocation

Prefer flat 1D arrays arr[r * C + c] over arrays-of-pointers to eliminate pointer-indirection cache misses.
