01
STAGE 01 · WHAT IT ISL4 · FUNDAMENTALS

What is Kruskal's Algorithm.

A Minimum Spanning Tree (MST) connects all V vertices of a weighted undirected graph using V - 1 edges with minimum total weight. By the Greedy Cut Property, the lightest edge crossing any vertex partition is guaranteed to belong to an MST.

Kruskal's algorithm sorts all E edges by ascending weight (O(E log E)), then scans them once using Disjoint Set Union (DSU) with path compression and union by rank/size (O(E · α(V)), where α(V) <= 4): if find(u) != find(v), union them and add the edge; otherwise skip it to avoid a cycle.

Union-Find Forest

Kruskal Sorted Edge Scan + Path-Compressed DSU Components

1.Early Exit: Stop as soon as edges_added == V - 1 without scanning heavier remaining edges.

2.Dual Heuristics: Pair path compression in find() with union by size/rank to guarantee inverse-Ackermann time.

3.Forest Check: If edges_added < V - 1 after scanning all edges, the input graph is disconnected.

Sorting edges once and merging with DSU avoids adjacency-list pointer chasing and excels on sparse edge lists.

02
STAGE 02 · WHY WE NEED ITL4 · FUNDAMENTALS

Why Kruskal Wins on Sparse Networks & Edge-List Streams.

In regional fiber-optic backbone planning (E = 3,100 candidate trenches) or image segmentation (Felzenszwalb-Huttenlocher with 256-bin Counting Sort), edges naturally arrive as a flat list. Sorting a flat array sequentially is CPU-cache-friendly and rejects cycle-forming edges in <1 ms.

64-Bit Weight Accumulation

Individual edge weights may fit in int32, but summing V - 1 edges overflows 32-bit integers—always accumulate total_weight in int64.

Iterative Path Halving

In constrained-stack environments or pre-compression trees, iterative path halving (while p[x] != x: p[x] = p[p[x]]; x = p[x]) avoids recursion overhead.

03
STAGE 03 · WHERE IT IS USEDL5 · APPLIED DESIGN

Where Kruskal Excels (and Where Prim's or Chu-Liu Wins).

Kruskal dominates sparse graphs (E = O(V)); dense graphs (E ≈ V²) and directed graphs require different algorithms.

ChoiceWhat it buysWhat it costs
Good Candidate: Sparse Graphs (`E <= 5V`) & ClusteringSequential flat-array sort + DSU beats Prim's binary-heap overhead on road, fiber, and k-NN graphs.Must validate `edges_added == V - 1` to catch disconnected components.
Avoid: Dense Graphs (`E ≈ V²`, e.g., 50M Euclidean Pairs)Prim's `O(V²)` without a heap avoids sorting 50M edges upfront.Sorting `O(V² log V)` edges wastes time and memory.
Avoid: Directed Minimum Spanning ArborescenceUse Edmonds' / Chu-Liu algorithm for directed minimum-cost spanning trees.Greedy cycle-free edge selection is invalid on directed graphs.
04
STAGE 04 · HOW IT IS MANAGEDL5 · APPLIED DESIGN

Kruskal's MST with Iterative Path-Halving DSU & Forest Guard.

Combine iterative path halving, union by size, early exit at V - 1 edges, and an explicit disconnected-graph check.

def kruskal_mst(n: int, edges: list[tuple[int, int, int]]) -> tuple[int, list[tuple[int, int, int]]]:
    parent = list(range(n))
    size = [1] * n

    def find(x: int) -> int:
        while parent[x] != x:
            parent[x] = parent[parent[x]]  # Iterative path halving
            x = parent[x]
        return x

    mst = []
    total_weight = 0  # Python int avoids 64-bit overflow; use int64 in Go/Java/C++
    for w, u, v in sorted(edges):
        ru, rv = find(u), find(v)
        if ru != rv:
            if size[ru] < size[rv]:
                ru, rv = rv, ru
            parent[rv] = ru
            size[ru] += size[rv]
            total_weight += w
            mst.append((w, u, v))
            if len(mst) == n - 1:
                break
    if n > 0 and len(mst) != n - 1:
        raise ValueError("Graph is disconnected; only a spanning forest exists")
    return total_weight, mst

Alternatives: Kruskal vs. Prim (Heap) vs. Radix-Sorted Kruskal.

Choose the MST variant based on graph density and edge-weight types.

ChoiceWhat it buysWhat it costs
Kruskal (Comparison Sort + DSU)Handles arbitrary 64-bit floats/negative weights cleanly on flat edge lists.`O(E log E)` sort dominates runtime.
Kruskal + Radix / Counting SortDrops sorting to `O(E)` for small integer or quantized weights (e.g., 256-bin image cuts).Only applies to bounded integer/quantized weights.
Prim's AlgorithmGrows a single tree from `src` without sorting all `E` edges upfront; wins on dense `E ≈ V²` graphs.Needs an adjacency list and priority queue with `decreaseKey` or lazy deletion.
