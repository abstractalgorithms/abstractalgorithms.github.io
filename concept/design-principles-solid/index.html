STAGE 01 · WHAT IT ISL4 · FUNDAMENTALS

What are SOLID, Clean Architecture & KISS.

SOLID is five modular design heuristics: SRP (one cohesive actor/reason to change), OCP (extend via new code without editing core switches), LSP (subtypes honor base contracts), ISP (focused role interfaces), and DIP (high-level policy depends on abstractions, not concrete I/O).

Clean / Hexagonal Architecture scales DIP to the system: dependencies point inward toward pure domain rules, never outward toward SQL, HTTP, or vendor SDKs. KISS is the essential counterweight—every abstraction pays cognitive rent and must earn its keep.

02
STAGE 02 · WHY WE NEED ITL4 · FUNDAMENTALS

Why Coupling Rots Codebases (and How Ports & Adapters Save Migrations).

Codebases rot in two opposite ways: 'Big Ball of Mud' handlers mixing SQL, Stripe SDKs, and business rules in 250-line methods, or 'Enterprise FizzBuzz' wrapping 3-field CRUD in 4 interface layers. Applying DIP at I/O boundaries lets core domain logic survive full database migrations untouched.

Clean Architecture Boundary

Inward Dependency Direction: Domain Core <- Application Ports <- Infra Adapters

Source-code dependencies point inward: infrastructure adapters implement domain-owned ports, never the reverse.

Hexagonal Architecture Saved a Ledger Migration

Because SettlementEngine only imported a domain LedgerPort interface (zero @Entity annotations), migrating from PostgreSQL to DynamoDB took 3 weeks in DynamoLedgerAdapter with zero edits to settlement rules.

Fixing an LSP Violation via ISP

ReadOnlyS3Store threw UnsupportedOperationException on put(), crashing workers expecting BlobStore. Splitting into ReadableBlobStore and WritableBlobStore caught invalid assignments at compile time.

03
STAGE 03 · WHERE IT IS USEDL5 · APPLIED DESIGN

Where Clean Architecture Belongs (and Where KISS / Vertical Slices Win).

Reserve full Ports & Adapters for the ~20% of your system holding complex invariants, money movement, or volatile external integrations.

ChoiceWhat it buysWhat it costs
Use Clean/Hexagonal: Core Domain & Volatile IntegrationsMillisecond unit tests, zero framework lock-in, safe DB/vendor swaps.DTO mapping boilerplate across HTTP -> Command -> Domain -> DB boundaries.
Use KISS / Vertical Slice: Simple CRUD & Read QueriesDirect SQL/jOOQ/SQLAlchemy projection queries avoid 4x ceremony and fight zero joins.N/A—simplicity is a feature when no complex invariants exist.
Avoid: Tight SIMD / Game-Physics Hot LoopsDirect value/struct loops preserve CPU cache locality.Virtual interface dispatch adds indirection overhead.
04
STAGE 04 · HOW IT IS MANAGEDL5 · APPLIED DESIGN

How to Enforce Boundaries in CI with ArchUnit / `import-linter`.

Architectural rules decay under deadline pressure unless automated as CI fitness functions. Use ArchUnit (Java) or import-linter (Python) to fail builds if domain imports infrastructure, sqlalchemy, or springframework. Place @Transactional at the Application UseCase boundary, not inside individual repositories.

# pyproject.toml — import-linter contract enforcing Clean Architecture in CI (Python)
[tool.importlinter]
root_package = my_app

[[tool.importlinter.contracts]]
name = "Domain must stay pure"
type = forbidden
source_modules = ["my_app.domain"]
forbidden_modules = ["my_app.infrastructure", "sqlalchemy", "fastapi", "httpx"]

STAGE 05 · ALTERNATIVESL6 · SCALE & TRADE-OFFS

Alternatives: Clean Architecture vs. Vertical Slice vs. Transaction Script.

Choose architectural ceremony proportional to domain complexity.

ChoiceWhat it buysWhat it costs
Clean / Hexagonal ArchitectureMaximum testability and infrastructure isolation for core domains.High boilerplate if cargo-culted onto simple `GET /health` or CRUD endpoints.
Vertical Slice ArchitectureGroups each feature's handler, validation, and query together with minimal cross-layer indirection.Can duplicate domain logic if rich invariants span multiple slices.
Transaction ScriptFastest to write and debug for simple scripts and admin CRUD.Degrades into a Big Ball of Mud if complex state machines accumulate.

STAGE 06 · PRODUCTION ARCHITECTUREL7 · STAFF / PRINCIPAL

Production Architecture: Pragmatic Hybrid (CQRS-Lite + Pure Core).

Combine Clean Architecture on the write path (Order invariants + CheckoutUseCase + Ports) with lightweight direct SQL projections on read-only endpoints (GET /orders/{id}), guarded by automated CI import checks.

Architectural Fitness

Pragmatic KISS vs. Clean Boundary Decision Flow

Only introduce interfaces and ports when you have >=2 implementations, an I/O boundary to fake, or complex invariants to protect.
