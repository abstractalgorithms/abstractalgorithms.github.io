Circuit Breakers & Resilience Patterns

Prevent cascading microservice outages by tripping circuit breakers when downstream failure thresholds are breached.

✓ When to Use

  • ✓Microservice HTTP calls to third-party APIs.
  • ✓Database connection attempts.

✕ When NOT to Use

  • ✕In-process local function calls.

Concept Lesson
Guided mode

A slow downstream payment gateway blocks API threads across the entire microservice mesh, triggering a total outage.

Context & Constraints — Human Reviewed

Why It Matters

A slow downstream payment gateway blocks API threads across the entire microservice mesh, triggering a total outage.

Core Architecture & Rules

  • →Closed State: Normal operation; tracks failure rates.
  • →Open State: Tripped; short-circuits requests immediately to fallback.
  • →Half-Open State: Allows trial requests to test downstream recovery.

Failure Modes & Mitigations

  • ⚖Flapping Circuit:Breaker rapidly switches between OPEN and CLOSED.

    Mitigation: Add evaluation sliding window size and recovery cooldown timeouts.

Example Usages

Netflix Hystrix / Resilience4j

Scenario: Recommendation service failure.

Outcome: Circuit trips OPEN; UI renders cached trending movies fallback.
