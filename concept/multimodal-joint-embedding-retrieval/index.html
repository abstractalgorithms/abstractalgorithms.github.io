Stage 1: Modality Encoders & L2-Normalized Projection Heads.

Why this matters: Understand how separate text, image-patch, and video-frame encoders project heterogeneous inputs onto a shared unit hypersphere.

A multimodal dual-encoder routes text tokens through a causal or bidirectional Transformer and images through a Vision Transformer (ViT) that splits each frame into fixed patches. Independent linear projection heads map both representations into a shared D-dimensional space (such as 768-D or 1150-D), followed by L2 normalization so every vector lies on the unit hypersphere and cosine similarity equals a single inner product.

FOUNDATION · DUAL-ENCODER PROJECTION

Projecting Text & Vision Features onto a Shared Unit Hypersphere

1.Modality Decoupling: Text and vision towers run independently, allowing offline document encoding and sub-15ms online query encoding.

2.Unit-Norm Invariant: L2 normalization ensures inner-product ANN indexes (MIPS) compute exact cosine similarity without magnitude bias.

Separate text and vision encoders map raw inputs into a unified L2-normalized embedding space where cross-modal similarity is a dot product.

02
foundation

Stage 2: InfoNCE vs. SigLIP Pairwise Sigmoid Contrastive Loss.

Why this matters: Compare global softmax InfoNCE against pairwise sigmoid loss (SigLIP) for scaling contrastive pretraining across GPU clusters.

CLIP optimizes symmetric InfoNCE cross-entropy across an N x N similarity matrix, requiring all-gather collectives across every GPU rank to compute the softmax denominator. SigLIP replaces softmax with independent pairwise binary sigmoid loss with learnable temperature t and bias b, removing global synchronization barriers and scaling linearly to 32,768+ batch sizes.

FOUNDATION · CONTRASTIVE OBJECTIVE

Eliminating Global All-Gather Bottlenecks with SigLIP Sigmoid Loss

1.Batch-Size Scaling: Removing the cross-GPU softmax denominator unlocks 32K+ batch sizes with lower memory and network overhead.

2.Hard Negative Density: Larger in-batch negative pools sharpen decision boundaries for fine-grained visual attributes.

SigLIP swaps CLIP's global softmax for pairwise binary sigmoid loss, removing cross-GPU synchronization bottlenecks.

03
intermediate

Stage 3: Video Keyframe Chunking & Perceptual Deduplication.

Why this matters: Collapse redundant 30 fps video streams into distinct semantic keyframes using histogram deltas and 64-bit pHash.

Encoding every frame of a 30 fps video wastes 60x GPU compute on static or near-identical frames. An ingestion pipeline pairs FFmpeg demuxing with Bhattacharyya HSV histogram delta detection (> 0.30) and a 64-bit perceptual hash (pHash) Hamming distance gate (>= 8) to emit roughly 0.5 high-signal keyframes per second.

INTERMEDIATE · VIDEO DEDUPLICATION

Two-Stage Scene & pHash Gate for 60x GPU Compute Reduction

1.60x Cost Reduction: Dropping redundant static frames cuts GPU encoder fleet size from 30 frames/sec to ~0.5 keyframes/sec.

2.Temporal Metadata: Each emitted keyframe retains frame_index and timestamp_sec for downstream sliding-window collapse.

Histogram scene detection and 64-bit pHash filtering reduce 30 fps video to ~0.5 unique keyframes per second before GPU inference.

04
intermediate

Stage 4: Matryoshka Representation & SQ8/PQ64 Quantization.

Why this matters: Shrink terabyte-scale FP32 vector corpora into tiered DRAM and NVMe memory footprints using SQ8, PQ64, and Matryoshka prefixes.

Storing 850M 1150-D FP32 vectors requires 3.91 TB before graph overhead. Scalar Quantization (SQ8) compresses each dimension to 1 byte (4x reduction) for sub-10ms DRAM HNSW lookup, while Product Quantization (PQ64) and Matryoshka nested prefixes (e.g., 128-D coarse scan -> 1150-D rescore) enable billion-scale NVMe DiskANN retrieval.

INTERMEDIATE · MEMORY TIERING

Compressing 3.91 TB FP32 Vectors into Hot SQ8 DRAM & Warm PQ64 NVMe

1.Hot vs. Warm Split: SQ8 HNSW serves high-priority items in <10ms from DRAM while PQ64 DiskANN holds the long tail on NVMe.

2.Matryoshka Flexibility: Nested prefix dimensions let search routers trade recall for latency dynamically under load.

SQ8 quantization fits hot HNSW graphs in DRAM while PQ64 DiskANN scales long-tail vectors on NVMe SSDs.

05
intermediate

Stage 5: Hybrid Scatter-Gather & Reciprocal Rank Fusion (RRF).

Why this matters: Combine dense cross-modal ANN recall with sparse BM25 lexical matching using rank-based Reciprocal Rank Fusion.

Dense joint embeddings capture visual semantics ('red SUV on bridge') but can miss exact part numbers, SKUs, or rare proper nouns where BM25 excels. Because dense cosine scores and unbounded BM25 scores are incommensurable, Reciprocal Rank Fusion (RRF with k=60) merges ranked lists purely by position without fragile score calibration.

INTERMEDIATE · HYBRID FUSION

Scale-Invariant Merging of Dense HNSW, DiskANN & Sparse BM25

1.Zero Score Calibration: RRF depends only on ordinal rank, avoiding drift when cosine or BM25 distributions shift.

2.Candidate Funnel: Fusing parallel Top-200 lists yields a high-recall Top-200 pool for expensive late-interaction reranking.

Parallel HNSW, DiskANN, and BM25 retrievers feed an RRF (k=60) merger that normalizes heterogeneous rankings into a unified Top-200 pool.

06
advanced

Stage 6: ColPali MaxSim Late-Interaction Reranking.

Why this matters: Recover fine-grained spatial and OCR-level visual precision using 2-bit quantized 32x32 patch embeddings and MaxSim.

Single-vector pooling averages away small text, chart axes, and dense table cells inside document images. ColPali retains a 32x32 grid of 1024 patch embeddings (128-D each, 2-bit quantized to 36 bytes/patch = 36 KB/page) and scores each query token against its maximum inner-product patch match (MaxSim) over the Top-200 RRF candidates.

ADVANCED · LATE INTERACTION

Token-to-Patch MaxSim Scoring Over 2-Bit Quantized Visual Grids

1.2-Bit Quantization Budget: SQ2 shrinks 1024 x 128-D FP16 patches from 13.1 TB to 1.84 TB across 50M pages with minimal recall loss.

2.OCR-Free Document Search: Patch-level MaxSim locates charts, diagrams, and small table values directly from pixels.

ColPali MaxSim scores Top-200 candidates across 1024 2-bit quantized patch tokens per page to achieve high visual-document precision.

07
advanced

Stage 7: Cross-Modal Alignment Drift Governance & Canary Gates.

Why this matters: Prevent silent embedding space corruption during model upgrades using golden anchor cosine drift checks.

If a newly deployed encoder shifts its vector geometry relative to the existing 850M-item index, live query vectors become incompatible with stored document vectors. Before promoting a model canary, an automated gate evaluates mean cosine drift across a 10,000-pair golden anchor dataset and aborts rollout if drift exceeds 0.03.

ADVANCED · ALIGNMENT GOVERNANCE

Golden Anchor Cosine Drift Gate for Zero-Downtime Encoder Rollouts

1.Zero Mixed-Space Queries: Blocking incompatible encoders prevents silent Recall@100 collapse against existing HNSW shards.

2.Automated Rollback: Any drift > 0.03 triggers an immediate canary abort and halts index synchronization.

A 10,000-pair golden anchor benchmark enforces mean cosine drift <= 0.03 before any encoder upgrade serves live traffic.
