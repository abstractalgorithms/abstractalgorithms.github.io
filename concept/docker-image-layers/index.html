What are Docker Images, Layers & OverlayFS.

Why this matters: The mechanism: understand how Docker Images, Layers & OverlayFS works from first principles.

An OCI/Docker image is a JSON manifest pointing to an ordered stack of immutable, compressed filesystem tarballs (layers), each capturing the delta of one RUN, COPY, or ADD instruction by its SHA-256 digest.

At startup, containerd + runc instruct Linux OverlayFS to mount the read-only image layers as lowerdir, attach a container-writable upperdir, and expose the unified view at merged. Ten containers on one host share a single physical copy of the base layers in page cache.

OverlayFS Union Mount

Read-Only SHA-256 Lower Layers Merged with Writable Upperdir

Lower layers are immutable and shared across pods; deleting a lower-layer file only writes a .wh.<file> whiteout in upperdir.

Engineering Decision Framework
Problem
How to implement Docker Images & Layers without hitting unbounded tail latency, state divergence, or operational fragility.
Naive Solution
Use a single unpartitioned path with unbounded retries and synchronous global coordination.
Why It Fails
Global coordination serializes throughput under load, while unbounded retries amplify transient stalls into full outages.
Alternatives
Compare synchronous strict-consistency paths against bounded asynchronous replication, local caching, or partitioned ownership.
Engineering Decision
When traffic spikes expose hidden coupling, order Dockerfile instructions from least-frequently changed to most-frequently changed, combine RUN cleanup in the same layer, and use multi-stage builds so build toolchains never ship to production.
Trade-Offs
Gains predictable p99 latency and fault isolation in exchange for explicit bounding, observability, and slightly higher implementation complexity.

How to Write Clean Dockerfiles & Audit Layers with `dive`

# syntax=docker/dockerfile:1.7
FROM golang:1.23-alpine@sha256:c10e7a2b AS builder
WORKDIR /src
COPY go.mod go.sum ./
RUN --mount=type=cache,target=/go/pkg/mod go mod download
COPY . .
RUN --mount=type=cache,target=/root/.cache/go-build \
    CGO_ENABLED=0 go build -trimpath -o /out/server ./cmd/server

FROM gcr.io/distroless/static-debian12:nonroot
USER 65532:65532
COPY --from=builder --chown=65532:65532 /out/server /server
ENTRYPOINT ["/server"]
