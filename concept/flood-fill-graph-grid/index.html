01
STAGE 01 · WHAT IT ISL4 · FUNDAMENTALS

What is Flood Fill.

Flood fill treats a 2D grid or raster image as an implicit graph where each cell (r, c) connects to its 4-directional (orthogonal) or 8-directional neighbors sharing a matching predicate (e.g., grid[nr][nc] == seedColor).

Starting from a seed (sr, sc), traversal visits every connected cell in the component and relabels it to newColor. Two invariants prevent catastrophic bugs: (1) guard if oldColor == newColor: return immediately, and (2) mark cells visited before pushing them onto the queue.

Cell Lifecycle

Flood Fill Cell State Transitions (Preventing Duplicate Enqueues)

Recoloring or marking visited at enqueue time (not pop time) prevents exponential duplicate insertions in diamond grids.

02
STAGE 02 · WHY WE NEED ITL4 · FUNDAMENTALS

Why Recursive DFS Crashes on Real Grids.

Each recursive stack frame consumes ~32–64 bytes. A serpentine path across a 1024 x 1024 grid (1 million depth) requires 32–64 MB of call stack—blowing past Linux's default 8 MB ulimit -s stack limit and crashing with a segfault. Worse, marking visited on pop instead of enqueue pushes shared diagonal neighbors multiple times, exploding queue memory.

Enqueue-Time Marking

Set grid[nr][nc] = newColor the instant a neighbor passes bounds and color checks, before appending to the queue.

Scanline Span-Fill

Process entire horizontal runs [x_left, x_right] per queue entry, shrinking frontier queue size by up to 10x on open 4K canvases.

STAGE 03 · WHERE IT IS USEDL5 · APPLIED DESIGN

Where Flood Fill Fits (and When to Use Union-Find or Dijkstra).

Use flood fill for single-seed region discovery; switch to Union-Find for repeated static reachability or Dijkstra for weighted paths.

ChoiceWhat it buysWhat it costs
Good Candidate: 4K Raster Bucket Fill (OpenCV)Scanline span-fill processes contiguous horizontal pixels sequentially, maximizing CPU prefetcher hits.Span boundary checks require careful off-by-one testing.
Good Candidate: Pre-Computed Navmesh Island IDsTagging walkable tiles with `islandId` (`uint16`) at map load turns runtime reachability into an O(1) comparison.Dynamic terrain edits require localized re-flooding.
Avoid: Shortest Weighted PathDijkstra or A* accounts for terrain movement costs and heuristics.Unweighted flood fill ignores edge weights completely.

STAGE 04 · HOW IT IS MANAGEDL5 · APPLIED DESIGN

Production-Safe Iterative BFS & Scanline Flood Fill.

Use an explicit collections.deque (or pre-allocated ring buffer) with an upfront old_color == new_color guard and enqueue-time mutation.

from collections import deque

def flood_fill_bfs(grid: list[list[int]], sr: int, sc: int, new_color: int) -> None:
    rows, cols = len(grid), len(grid[0])
    old_color = grid[sr][sc]
    if old_color == new_color:
        return  # Guard against no-op infinite loop

    grid[sr][sc] = new_color
    q = deque([(sr, sc)])
    while q:
        r, c = q.popleft()
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == old_color:
                grid[nr][nc] = new_color  # Mark BEFORE enqueue
                q.append((nr, nc))

STAGE 05 · ALTERNATIVESL6 · SCALE & TRADE-OFFS

Alternatives: Iterative BFS vs. Iterative DFS vs. Scanline Span-Fill.

Choose the traversal strategy based on memory bounds, cache locality, and whether minimum hop distance matters.

ChoiceWhat it buysWhat it costs
Iterative BFS (`deque`)Expands in concentric waves (minimum hop distance) and bounds frontier to `O(min(R, C))` on simple shapes.Enqueues every individual pixel on open 4K regions.
Scanline Span-Fill (Queue-Linear)10x smaller queue and sequential horizontal memory reads friendly to CPU cache.More complex span-merging logic than 12-line BFS.
Two-Pass Union-Find (Disjoint Set)Labels all connected components in a static binary mask in two cache-linear raster scans.Processes the entire image even if you only need one small clicked region.

STAGE 06 · PRODUCTION ARCHITECTUREL7 · STAFF / PRINCIPAL

Production Pattern: Pre-Tagged Island IDs & Fixed-Range Tolerance.

In multiplayer game servers and image editors, flood fill must also guard against color-tolerance drift (comparing candidates against the immutable seedColor, never the neighbor's color) and immutable grid snapshots (using a separate visited bitset when concurrent readers inspect the map).
