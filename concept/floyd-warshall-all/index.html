TL;DR30-second simplified summary
▾

Core Mechanics: Floyd-Warshall computes the shortest path between every pair (i, j) in a weighted directed or undirected graph using the dynamic-programming recurrence: dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) At step k.

Visual & Structural Flow: Depicts Floyd-Warshall Intermediate Vertex Relaxation (k Outermost) (BASE MATRIX (k=-1) -> RELAX VIA k (0..V-1) -> NEG CYCLE DETECTED); Lock-Free Double-Buffered All-Pairs Matrix Swap (PoP Telemetry -> FW Builder Thread -> Atomic Matrix Ptr -> Routing Readers).

Trade-Offs & Production: Pick the all-pairs algorithm based on graph density and whether negative weights exist. Because Floyd-Warshall mutates dist[i][j] in-place across k iterations, serving routers must never read the matrix mid-computation.

What is Floyd-Warshall.

Why this matters: The mechanism: understand how Floyd-Warshall works from first principles.

Floyd-Warshall computes the shortest path between every pair (i, j) in a weighted directed or undirected graph using the dynamic-programming recurrence:

dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

DP Invariant

Floyd-Warshall Intermediate Vertex Relaxation (k Outermost)

Iterating k outermost lets the 3D DP table collapse to a single V x V matrix updated in-place.

Lifecycle & Failure Recovery

Safe k-i-j Loop, Overflow Guard & Negative-Cycle Detection

INF = 10**15

def floyd_warshall(n: int, edges: list[tuple[int, int, int]]):
    dist = [[0 if i == j else INF for j in range(n)] for i in range(n)]
    nxt = [[i if i == j else -1 for j in range(n)] for i in range(n)]
    for u, v, w in edges:
        if w < dist[u][v]:
            dist[u][v], nxt[u][v] = w, v

    for k in range(n):  # MUST be outermost
        for i in range(n):
            if dist[i][k] == INF:
                continue
            for j in range(n):
                if dist[k][j] == INF:
                    continue
                cand = dist[i][k] + dist[k][j]
                if cand < dist[i][j]:
                    dist[i][j] = cand
                    nxt[i][j] = nxt[i][k]

    has_neg_cycle = any(dist[i][i] < 0 for i in range(n))
    return dist, nxt, has_neg_cycle

ChoiceWhat it buysWhat it costs
Floyd-Warshall (`O(V³)`)Handles negative weights, 3 nested loops, zero heap allocations, fits `V <= 512` in L2/L3 cache.Unusable for `V > 1,500` due to cubic scaling.
Johnson's Algorithm (`O(V² log V + VE)`)Reweights negative edges via 1 Bellman-Ford pass, then runs `V` fast Dijkstras on sparse graphs.Higher implementation complexity and heap overhead on dense graphs.
