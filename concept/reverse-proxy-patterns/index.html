STAGE 01 · WHAT IT ISL4 · FUNDAMENTALS

What is a Reverse Proxy.

A reverse proxy (Envoy, NGINX, HAProxy) sits in front of origin servers and acts as a single L7 termination boundary. It terminates client TCP/TLS 1.3, buffers slow client bodies (blocking slowloris attacks), enforces auth/rate limits, and multiplexes normalized HTTP/2 or gRPC requests over persistent upstream connection pools.

Unlike an L4 TCP load balancer, an L7 reverse proxy inspects HTTP headers/paths, runs Power-of-Two-Choices (P2C) or consistent hashing, and performs passive outlier detection to eject failing pods.

Edge Multiplexing Tier

L7 Reverse Proxy TLS Offload & Per-Cluster Upstream Pools

1.1. TLS & Slowloris Shield: Proxy absorbs untrusted WAN jitter and TLS handshakes so origin workers never stall on slow sockets.

2.2. Per-Service Pools: Isolating connection pools per upstream cluster prevents one slow service from starving all others.

3.3. Outlier Ejection: Consecutive 5xx responses trip passive circuit breakers and eject sick pods for a cooldown window.

Edge reverse proxies turn chaotic public internet connections into bounded, pooled internal RPCs.

02
STAGE 02 · WHY WE NEED ITL4 · FUNDAMENTALS

Why we need Reverse Proxies (Keep-Alive Races & Global Pools).

Exposing application servers directly to the internet forces every service to manage TLS certificates, connection floods, and HTTP/1.1 head-of-line blocking. Even with a proxy, two subtle bugs cause production 502s: (1) Keep-Alive Timeout Race: if the upstream app's idle timeout (e.g., 60s) is shorter than the proxy's pool timeout (65s), the proxy writes onto a socket the backend just closed, returning 502 Bad Gateway; (2) Shared Unbounded Pools let one noisy microservice exhaust all proxy workers.

Keep Upstream Idle Timeout > Proxy Pool Timeout

Always configure the backend server's keep-alive idle timeout (e.g., 65s) strictly higher than the proxy's upstream idle timeout (e.g., 55s).

Use Consistent Hashing for Stateful/Cache Backends

Route by x-tenant-id or key hash to preserve L1 cache locality on stateful pods, while using P2C for stateless APIs.

STAGE 03 · WHERE IT IS USEDL5 · APPLIED DESIGN

Where Reverse Proxies fit (and where L4 Pass-Through wins).

Use L7 reverse proxies for HTTP/gRPC routing, TLS offload, and canary traffic splitting; use L4 DSR/Maglev when zero TLS decryption or raw packet throughput is needed.

ChoiceWhat it buysWhat it costs
Good Candidate: Multi-Tenant HTTP/gRPC Edge GatewaysProvides weighted canary routing, gRPC HTTP/2 load balancing, header auth, and outlier detection.Adds ~0.5–3 ms L7 parsing overhead and requires proxy buffer/timeout tuning.
Avoid: Ultra-High-Bandwidth Media Streaming / Raw TCPUse L4 DSR (Direct Server Return) / IPVS so video/file egress bypasses the proxy completely.Proxying 100 Gbps of video through L7 user-space buffers wastes CPU and NIC bandwidth.
04
STAGE 04 · HOW IT IS MANAGEDL5 · APPLIED DESIGN

How Envoy Circuit Breakers, Outlier Detection & Pools are configured.

Configure per-cluster circuit_breakers (max_connections, max_pending_requests), passive outlier_detection (consecutive_5xx), and strict timeout budgets smaller than client timeouts.

# Envoy upstream cluster with isolated pool, circuit breaker & outlier detection
name: payments_service
lb_policy: LEAST_REQUEST  # Power-of-Two-Choices (choice_count=2)
common_http_protocol_options:
  idle_timeout: 55s       # Strictly < backend keep-alive (65s)
circuit_breakers:
  thresholds:
    - max_connections: 256
      max_pending_requests: 128
      max_retries: 3
outlier_detection:
  consecutive_5xx: 5
  interval: 10s
  base_ejection_time: 30s
  max_ejection_percent: 50

STAGE 05 · ALTERNATIVESL6 · SCALE & TRADE-OFFS

Alternatives: Envoy vs. NGINX vs. L4 Load Balancer.

Select the proxy layer based on dynamic control-plane needs, gRPC/HTTP2 support, and throughput.

ChoiceWhat it buysWhat it costs
Envoy ProxyDynamic xDS config without reloads, native gRPC HTTP/2 L7 balancing, P2C, and rich outlier detection.Higher memory footprint and steeper xDS configuration complexity than static NGINX.
NGINX / OpenRestyBattle-tested static file/cache serving, tiny RAM footprint, and Lua extensibility.Config reloads spawn new worker processes; dynamic service discovery is less native than Envoy xDS.
L4 Load Balancer (NLB / IPVS)Line-rate kernel/NIC forwarding with zero TLS termination overhead.Cannot balance individual gRPC/HTTP2 multiplexed streams across new pods.

STAGE 06 · PRODUCTION ARCHITECTUREL7 · STAFF / PRINCIPAL

Production example: 50k RPS Multi-Tenant Edge Tier.

An Envoy edge tier handles 50,000 RPS across 50 microservices: terminating TLS 1.3 with session tickets, enforcing per-tenant token-bucket limits, routing via P2C across isolated per-service connection pools, and ejecting 5xx pods via outlier detection (<3 ms p99 overhead).
