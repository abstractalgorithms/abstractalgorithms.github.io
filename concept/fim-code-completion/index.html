The idea to keep with you

TL;DR30-second simplified summary
▾

Standard left-to-right LLM generation only sees code before the cursor, ignoring closing braces, return statements, and types below the cursor. Fill-in-the-Middle (FIM) solves this by splitting the editor buffer at the cursor and packing tokens in Prefix-Suffix-Middle (<PRE> prefix <SUF> suffix <MID>) order during training and inference.

Because IDE autocomplete fires on nearly every pause in typing, latency budgets are brutal (< 150 ms end-to-end). Production engines pair a fast 7B/13B FIM model with RadixAttention prefix caching (since the top of the file rarely changes across keystrokes), Tree-sitter AST symbol retrieval across open tabs, and Speculative Decoding (or prompt-lookup drafting) to stream ghost text before the user types the next character.

Architectural Mechanics

1.In-Flight Cancellation: Every new keystroke aborts the previous SSE request so GPU queues never fill with obsolete typing.

2.Prefix Cache Synergy: Because file top lines rarely change, RadixAttention skips re-prefilling 70-85% of prompt tokens.

def build_fim_prompt(prefix: str, suffix: str, ast_context: str, max_chars: int = 12000) -> str:
    if not prefix and not suffix:
        raise ValueError('Editor buffer cannot be completely empty')
    ctx_budget = min(len(ast_context), max_chars // 4)
    pre_budget = (max_chars - ctx_budget) * 2 // 3
    suf_budget = max_chars - ctx_budget - pre_budget
    trimmed_ctx = ast_context[:ctx_budget]
    trimmed_pre = prefix[-pre_budget:] if pre_budget > 0 else ''
    trimmed_suf = suffix[:suf_budget] if suf_budget > 0 else ''
    return f'<PRE>{trimmed_ctx}\n{trimmed_pre}<SUF>{trimmed_suf}<MID>'
STAGE 03 · SAFE IMPLEMENTATION

FIM Prompt Packer with Token Budget

1.Cursor Proximity First: Truncate from the top of prefix and bottom of suffix—never near the cursor.

2.Ast-First Cache Stability: Place stable cross-file imports at the very top so RadixAttention prefix hashes stay warm.

3.Line-Boundary Alignment: Snap truncation to newline boundaries to avoid broken partial tokens.

Budgeted FIM packing reserves space for AST imports while keeping lines closest to the cursor intact.
