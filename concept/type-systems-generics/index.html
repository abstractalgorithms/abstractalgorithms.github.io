THE BIG IDEA / Key takeaway · CONCEPT GUIDE

Type erasure keeps binaries small but loses runtime type info and boxes primitives; monomorphization gives zero-cost specialization and inlining at the expense of compile time and binary size.

01 / The idea

Foundational mechanics & core principles

Generics eliminate unsafe Object/void* casts and duplicated boilerplate across collections, async futures, and API wrappers—while their compilation strategy directly determines memory layout, CPU cache density, and compile times.

  • Type Erasure (Java, TypeScript): The compiler checks statically and erases it to Object (or its upper bound) in bytecode/JS; you cannot do new T() or x instanceof List, and primitives (int) must be boxed (Integer, 16+ bytes heap overhead) until Project Valhalla.
  • Monomorphization (Rust, C++, Zig): The compiler emits a dedicated machine-code copy for each concrete T (Vec, Vec), enabling unboxed contiguous memory, SIMD, and full inlining—at the cost of larger binaries and slower builds.
