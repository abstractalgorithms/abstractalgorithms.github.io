Rate Limiting & Token Buckets

Protect downstream APIs and services from Denial-of-Service spikes using Token Bucket and Sliding Window Log algorithms.

✓ When to Use

  • ✓Public API endpoints exposed to third-party developers.
  • ✓Authentication / login routes.
  • ✓Costly AI LLM inference endpoints.

✕ When NOT to Use

  • ✕Internal microservice IPC where mesh circuit breaking is preferred.

Why It Matters

Core Architecture & Rules

  • →Token Bucket fills tokens at a constant rate; permits short bursts.
  • →Sliding Window Counter combines window counters with weighted overlap percentages.

Failure Modes & Mitigations

  • ⚖Race Condition in Counter:Non-atomic counter updates across gateway nodes.

    Mitigation: Execute Redis Lua scripts for atomic counter updates.
