Functional Requirements

  • Bloom Filters answer "definitely not in this set" in constant time with zero false negatives.
  • HyperLogLog counts billions of unique elements in 12 KB with ±0.81% error.

Deep Dive: Stage 2 — How Each Structure Works Mechanically

  • Bloom Filter — bit array with k hash functions.

Deep Dive: Stage 3 — Deep Dive: When Approximation Guarantees Hold

  • The power of probabilistic structures is not that they are occasionally accurate — it is that their error bounds are mathematically provable regardless of the data distribution.
  • You can deploy them knowing exactly how wrong they can be in the worst case.
  • The Internals For a Bloom Filter with m bits, k hash functions, and n inserted elements, the false positive probability is p = (1 - e^(-kn/m))^k .
  • The optimal k that minimizes p for a given m and n is k = (m/n) × ln(2) .

Deep Dive: Stage 5 — Real-World Applications

  • These structures appear in production systems wherever streams are large and memory is constrained.
  • Google Chrome embeds a Bloom Filter in every browser installation to check URLs against a list of known-malicious domains.
  • The filter allows Chrome to answer "this URL is definitely safe" locally in microseconds, without a round-trip to Google's servers.
  • The small fraction of false positives triggers a network lookup — a modest cost compared to the privacy and latency impact of sending every URL to a remote server.
