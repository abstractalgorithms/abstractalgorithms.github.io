SQL Query Tuning: Index Seeks, Scans, Clustered & Covering Indexes

Relational query execution hinges on whether the optimizer executes an Index Seek (direct O(log N) B-Tree root-to-leaf traversal) or an Index/Table Scan (O(N) sequential page reads). When non-clustered indexes lack requested SELECT columns, the engine must perform a Key/RID Lookup back to clustered index pages for every row, triggering catastrophic random disk I/O.
