The idea to keep with you

When a single bottleneck threatens end-to-end availability, key staging branches by deterministic `run_id` and overwrite/replace partitions atomically so Airflow retries never duplicate settlement rows.

TL;DR30-second simplified summary
▾

When a 200-executor Spark settlement job crashes at 80% completion and Airflow retries it, naive INSERT INTO pipelines leave duplicate partial rows in the live settlement table—corrupting merchant payouts.

Using Apache Iceberg Write-Audit-Publish (WAP), each run_id writes deterministically to a staging branch, runs automated Great Expectations / SQL invariant checks (SUM(debit) == SUM(credit), zero duplicate tx_id), and atomically replaces the target partition on main.

Think of Idempotent Partition Overwrite & Audit Gate as the intuition layer for Design an Idempotent Financial Settlement DAG Pipeline with Atomic WAP: Implement settle_partition_idempotent to reset the run branch, compute settlement, audit, and promote or quarantine.

def settle_partition_idempotent(spark, catalog, partition_date: str, run_id: str) -> None:
    branch = f'settle_{partition_date}_{run_id}'
    catalog.create_or_reset_branch(branch)
    spark.compute_settlement(partition_date).write_iceberg(branch=branch, mode='overwrite_partition')
    audit = spark.audit_conservation(branch, partition_date)
    if audit['imbalance_cents'] != 0 or audit['dup_tx_count'] > 0:
        catalog.quarantine(branch)
        raise ValueError(f'Settlement audit failed: {audit}')
    catalog.atomic_publish(branch, target='main')
STAGE 03 · SAFE IMPLEMENTATION

Idempotent Partition Overwrite & Audit Gate

1.Branch Reset on Retry: Resetting settle_<dt>_<run_id> at task start eliminates leftover files from killed executors.

2.Strict Audit Exception: Raise AuditError before catalog publish if any invariant check fails.

3.Zero Side Effects on Main: Main remains untouched throughout retries until the final CAS commit.

Resetting the staging branch per run_id and gating publish on audit assertions makes Airflow retries idempotent.
