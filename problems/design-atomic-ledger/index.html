TOCTOU Race Conditions & Atomic Compare-And-Swap (CAS)
Time-of-Check to Time-of-Use (TOCTOU) race conditions occur when state validated in step 1 changes before step 2 mutates it; Atomic Compare-And-Swap (CAS) closes the gap in a single indivisible operation.
Optimistic Concurrency Control
A lock-free concurrency pattern that lets readers and writers proceed without blocking, validating at commit time via a version number or ETag that no one else modified the record.
Deadlock Detection & Prevention
Identifying and resolving circular wait conditions—where two or more threads or database transactions hold locks each other needs—via wait-for graph cycle detection, timeouts, or canonical lock ordering.

def execute_atomic_debit(cur, account_id: str, amount: int, idem_key: str, payload_hash: str) -> dict:
    if amount <= 0:
        raise ValueError('Debit amount must be positive')
    cur.execute(
        'INSERT INTO idempotency_keys(key, payload_hash, status) VALUES (%s, %s, %s) ON CONFLICT (key) DO NOTHING',
        (idem_key, payload_hash, 'IN_PROGRESS'),
    )
    if cur.rowcount == 0:
        return {'status': 'DUPLICATE_OR_IN_FLIGHT'}
    cur.execute(
        'UPDATE accounts SET balance = balance - %s, version = version + 1 WHERE id = %s AND balance >= %s RETURNING balance, version',
        (amount, account_id, amount),
    )
    row = cur.fetchone()
    if row is None:
        raise ValueError('Insufficient funds or missing account')
    return {'status': 'COMMITTED', 'balance': row[0], 'version': row[1]}
STAGE 03 · SAFE IMPLEMENTATION

Atomic Conditional Debit & Idempotency Gate

1.Fail Fast on Bad Input: Reject non-positive debit amounts before acquiring database connections.

2.Explicit Row-Count Check: If UPDATE affects 0 rows, roll back the idempotency claim and raise InsufficientFunds.

3.Cached Replay: If INSERT conflicts with matching payload_hash, return the persisted receipt immediately.

Validating positive amounts, checking INSERT conflict, and inspecting UPDATE row counts prevent double-debits.
