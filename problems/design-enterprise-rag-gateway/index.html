01
SYSTEM-DESIGN · STAGE 01L4 · FUNDAMENTALS

ACL-filtered Hybrid Retrieval & Reranking.

Combine dense HNSW vector search with sparse BM25 lexical search using Reciprocal Rank Fusion (RRF), filtering strictly by the user's document ACLs before ranking. Read more on how Input & Output Tokens shape prompt budgets.

ChoiceWhat it buysWhat it costs
Semantic Cache in RedisSub-20ms cache hits for recurring queriesMust key cache by `(tenant_id, acl_group)` to prevent cross-tenant data leaks

Insight 1

Enforce tenant/role ACL filters inside the vector index metadata filter—never filter only after retrieving Top-K.

Insight 2

Use a lightweight cross-encoder reranker to narrow Top-50 hybrid hits down to the 5 sharpest chunks.

02
SYSTEM-DESIGN · STAGE 02L5 · APPLIED DESIGN

Token Budgeting, Prefix Caching & Rate Limiting.

Track token-per-minute (TPM) quotas in Redis alongside request-per-minute limits, and place static system prompts at index 0 so the LLM engine reuses KV prefix caches.

Insight 1

Reserve max_tokens for output before fitting retrieved chunks into the context window.

Insight 2

Stream responses over SSE so users perceive low latency even when Decode takes several seconds.

Cross-Tenant Semantic Cache Leak

User B hits a cached answer generated from User A's confidential document.
