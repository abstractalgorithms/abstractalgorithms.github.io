STAGE 02 · IMPACTL5 · APPLIED DESIGN

RecursionError crashes and duplicate-edge false cycles.

Why this matters: The problem: see what breaks without RecursionError crashes and duplicate-edge false cycles under real concurrency or scale.

Two subtle bugs break naive graph validators at V = 100,000:

  1. Call-Stack Crash: Python's default sys.getrecursionlimit() is 1,000; a linear chain of 5,000 courses crashes recursive DFS with RecursionError.
  2. Duplicate-Edge False Positives: If [2, 1] appears twice and you deduplicate adj[1] without deduplicating in_degree[2], in_degree[2] never reaches 0 and falsely reports a cycle.
  3. Disconnected Subgraphs: Starting traversal only at node 0 misses cycles in nodes 500..505.

STAGE 04 · ENTERPRISE SOLUTIONL6 · SCALE & TRADE-OFFS

Enterprise solution: Deduplicated Kahn's BFS + Iterative Cycle Witness.

Why this matters: Operational control: configure bounds, failure handling, and safe production defaults.

Combine two O(V + E) iterative passes (~12 MB total heap in CPython):

  • Edge Deduplication: Deduplicate (course, prereq) pairs while building adj[prereq] and in_degree[course] in the exact same loop.
  • Kahn's BFS: Enqueue all nodes with in_degree == 0 (covering all disconnected components). Pop with collections.deque, append to order, and decrement neighbors. If len(order) == numCourses, return order.
  • Iterative 3-Color DFS Witness: If len(order) < numCourses, run an explicit heap stack (node, iter_idx) with states 0/1/2 and parent[] to slice out the exact minimal cycle.
Iterative 3-Color DFS

Heap-Allocated Stack State Transitions (Zero Recursion)

An explicit (node, idx) stack simulates DFS on the heap, avoiding C-stack limits on 100,000-node chains.

from collections import deque

def schedule_courses(num_courses: int, prerequisites: list[list[int]]) -> tuple[list[int], list[int]]:
    adj: list[list[int]] = [[] for _ in range(num_courses)]
    in_deg = [0] * num_courses
    seen = set()
    for course, prereq in prerequisites:
        if (prereq, course) not in seen:
            seen.add((prereq, course))
            adj[prereq].append(course)
            in_deg[course] += 1

    q = deque(i for i in range(num_courses) if in_deg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            in_deg[v] -= 1
            if in_deg[v] == 0:
                q.append(v)
    if len(order) == num_courses:
        return order, []

    # Iterative 3-color DFS for exact cycle witness
    state = [0] * num_courses
    parent = [-1] * num_courses
    for start in range(num_courses):
        if state[start] != 0:
            continue
        stack = [[start, 0]]
        state[start] = 1
        while stack:
            u, idx = stack[-1]
            if idx < len(adj[u]):
                v = adj[u][idx]
                stack[-1][1] += 1
                if state[v] == 0:
                    state[v] = 1
                    parent[v] = u
                    stack.append([v, 0])
                elif state[v] == 1:
                    cycle = [v]
                    cur = u
                    while cur != v:
                        cycle.append(cur)
                        cur = parent[cur]
                    cycle.append(v)
                    return [], cycle[::-1]
            else:
                state[u] = 2
                stack.pop()
    return [], []
