C2 Escape Analysis Classification

NoEscape (Scalar Replacement) vs. ArgEscape / GlobalEscape

Objects classified as NoEscape are decomposed into CPU registers/stack slots; failing inlining forces heap TLAB allocation.

STAGE 04 · ENTERPRISE SOLUTIONL6 · SCALE & TRADE-OFFS

Enterprise Solution: Inlining-Friendly Hot Paths & Zero-Allocation Primitives.

Why this matters: Operational control: configure bounds, failure handling, and safe production defaults.

Design hot-path code so HotSpot C2 can inline and scalar-replace every temporary value:

  • Respect C2 Inlining Thresholds: Keep hot helpers under -XX:MaxInlineSize=35 bytecodes (or warm them past -XX:FreqInlineSize=325) and avoid megamorphic virtual calls on the hot path.
  • Avoid Phi-Node Escapes: Compute primitives first (long finalAmt = valid ? amt : 0L;) instead of merging new Money() with Money.ZERO.
  • Primitive Packing & ThreadLocal Scratch: Pass primitive long minor units + int currency codes, reuse ThreadLocal<byte[]> scratch buffers, and verify < 50 MB/sec allocation via JMH -prof gc.
JVM Memory Allocation Tiers

Registers / Stack Frame vs. TLAB Eden vs. Old Gen

1.Stack Frame: Holds Local Variable Array, Operand Stack, and Frame Data (-Xss1m).

2.Heap Layout: 12B Compressed OOP header (8B Mark + 4B Klass) + fields + 8B align.

3.Lock Elision: NoEscape synchronized objects (e.g. local StringBuffer) elide locks.

4.Monomorphic Calls: Keep hot-path call sites monomorphic/bimorphic for C2 inlining.

Keeping hot methods small and monomorphic lets C2 scalar-replace wrappers into registers with zero GC pressure.

// Heap layout with Compressed OOPs (-XX:+UseCompressedOops):
// [8B Mark Word][4B Klass Ptr][8B long minorUnits][4B int currencyCode] = 24 bytes
public record Money(long minorUnits, int currencyCode) {}

public final class FastPaymentRouter {
    private static final int NO_ROUTE = -1;

    public long routeAndPrice(long amountMinor, int regionCode, RouteTable table, boolean debug) {
        // Scalar-replaceable local value if inlined; or even better, direct primitive math
        FeeBreakdown breakdown = computeFee(amountMinor, regionCode);
        int routeId = table.lookupFast(regionCode, breakdown.tier);
        if (routeId == NO_ROUTE) {
            return -1L;
        }
        if (debug) {
            logRoute(routeId, breakdown.total);
        }
        return breakdown.total;
    }

    // < 35 bytecodes, final: guaranteed C2 inline -> FeeBreakdown is NoEscape -> Scalar Replaced (0B)
    private FeeBreakdown computeFee(long amountMinor, int regionCode) {
        long fee = (amountMinor * (regionCode == 1 ? 15L : 25L)) / 10_000L;
        int tier = amountMinor > 100_000L ? 2 : 1;
        return new FeeBreakdown(amountMinor + fee, tier);
    }

    private static final class FeeBreakdown {
        final long total;
        final int tier;
        FeeBreakdown(long total, int tier) { this.total = total; this.tier = tier; }
    }

    private void logRoute(int routeId, long total) { /* cold path */ }
}

// BAD: Phi node merges new Money (NoEscape) with static ZERO (GlobalEscape) -> forces heap allocation!
// Money m = valid ? new Money(amt, 1) : Money.ZERO;

// GOOD: Compute primitive first; single allocation site or pure primitive path
long finalAmt = valid ? amt : 0L;
Money m = new Money(finalAmt, 1);
