01 / UnderstandFailure & constraints

Clarify what is failing.

At batch=1, 70B decoding is strictly HBM-bandwidth-bound (reading 140 GB of weights for 1 token's math). Adding 5 more tokens increases FLOPs 6x while keeping HBM weight reads constant, utilizing idle Tensor Cores.

Design objective

Compute HBM weight read time: 17.5 GB/GPU / 3.35 TB/s ~= 5.2 ms + AllReduce overhead.

Requirements

  • Guarantee exact mathematical equivalence to standard autoregressive sampling from the 70B target model (zero quality degradation).
  • Achieve >= 2.4x wall-clock speedup on low-batch interactive requests (batch size 1-8) without exceeding 80 GB HBM per GPU.
  • Manage KV-cache allocation and rollback cleanly when draft tokens are rejected mid-sequence.
  • Support continuous batching across heterogeneous requests with varying acceptance rates.

Constraints

  • 8x H100 SXM5 (80 GB HBM3 each, 3.35 TB/s memory bandwidth, 989 TFLOPS BF16 Tensor Core).
  • 70B BF16 weights occupy ~140 GB (~17.5 GB/GPU under TP=8); KV cache + draft model must fit in remaining ~62.5 GB/GPU.
  • Draft model forward pass + verification overhead must stay below 15 ms per K-token step.
Known failure modes

Running speculative decoding at batch=64 pushes batch_tokens=384 past the ridge point, causing compute-bound slowdown.

  1. 01Autoregressive Draft Rollout: Draft model generates K=5 candidate tokens sequentially, caching their logits q_1..q_K.
  2. 02Parallel Target Verification: 70B model evaluates all K+1 positions in a single batched forward pass using a causal attention mask.
  3. 03Lossless Rejection Sampling: Accept prefix while r < min(1, p_i/q_i); on first reject, sample 1 token from norm(max(0, p_i - q_i)).
  4. 04Sync State & Free Rejected Blocks: Truncate draft and target KV-cache pointers to accepted_len and feed the final accepted token to the drafter.
  5. 05Adapt K to Rolling Alpha: Adjust K in [0..8] based on exponential moving average of acceptance rate and current batch size.
Drafting runs without tensor-parallel AllReduce overhead; target verification amortizes 140 GB HBM reads across K+1 tokens.

The invariants

  • Iterate i from 0 to K-1 comparing target p[i, x_i] and draft q[i, x_i].
  • Accept if uniform(0,1) < min(1, p/q); on first rejection, normalize max(0, p[i] - q[i]) and sample replacement.
  • If all K tokens are accepted, sample bonus token from p[K].
03 / Trace the lifecycleKey decisions

Follow the execution path.

Placing a standalone 1B draft model unsharded on GPU 0 avoids 8-way NVLink AllReduce overhead (saving ~15 ms per K=5 step), while EAGLE-2 heads offer higher acceptance rates if custom-trained for the target model.

Step 1

Quantify NVLink AllReduce tax on small models: ~0.48 ms/token across 16 layers.

Step 2

Compare standalone 1B drafter (zero training, separate KV cache) vs EAGLE-2 (reuses target hidden states, higher alpha).

Step 3

Choose unsharded GPU 0 placement for standalone drafter, or EAGLE-2 when training budget is available.

04 / ImplementConfiguration & code

Build the safeguards.

PagedAttention tracks logical-to-physical block mappings per request; after verification, each request updates its `accepted_len` independently and frees only trailing physical blocks beyond `accepted_len`.

1. Reference implementation

PYTHON · Solution
import random
from typing import List

def speculative_sample(
    draft_tokens: List[int],
    q_probs: List[List[float]],  # shape [K, V]
    p_probs: List[List[float]],  # shape [K+1, V]
) -> List[int]:
    accepted: List[int] = []
    for i, tok in enumerate(draft_tokens):
        p_tok = p_probs[i][tok]
        q_tok = max(q_probs[i][tok], 1e-12)
        if random.random() < min(1.0, p_tok / q_tok):
            accepted.append(tok)
        else:
            # Sample from residual distribution norm(max(0, p_i - q_i))
            residual = [max(0.0, p - q) for p, q in zip(p_probs[i], q_probs[i])]
            total = sum(residual)
            if total <= 0.0:
                residual = p_probs[i]
                total = sum(residual)
            r = random.random() * total
            cum = 0.0
            for vocab_id, prob in enumerate(residual):
                cum += prob
                if cum >= r:
                    accepted.append(vocab_id)
                    return accepted
            accepted.append(len(residual) - 1)
            return accepted
    # All K accepted -> sample bonus token from p_probs[K]
    r = random.random()
    cum = 0.0
    for vocab_id, prob in enumerate(p_probs[len(draft_tokens)]):
        cum += prob
        if cum >= r:
            accepted.append(vocab_id)
            return accepted
    accepted.append(len(p_probs[-1]) - 1)
    return accepted

2. Harden for scale

PagedAttention tracks logical-to-physical block mappings per request; after verification, each request updates its `accepted_len` independently and frees only trailing physical blocks beyond `accepted_len`.

PYTHON · Scale hardening
def rollback_kv_cache(block_table: list[int], base_len: int, n_accepted: int, block_size: int = 16, free_pool: list[int] = None) -> int:
    new_len = base_len + n_accepted
    needed_blocks = (new_len + block_size - 1) // block_size
    while len(block_table) > needed_blocks:
        freed_block = block_table.pop()
        if free_pool is not None:
            free_pool.append(freed_block)
    return new_len

3. Operational controls

Step 1

Store `seq_len` before drafting as `base_len`.

Step 2

After verification yields `n_accepted` tokens, set `new_len = base_len + n_accepted`.

Step 3

Free any physical KV blocks whose start offset >= `new_len`, and mask attention using ragged `cu_seqlens`.

Implementation note

Requires storing draft probability distributions q_probs[0..K-1] until verification completes.

Prove the fix works.

Disaggregated prefill/decode isolates compute-heavy prefill nodes from latency-sensitive speculative decode nodes, while tree verification checks multiple draft branches in one target pass.

PYTHON · Verification
# Tree attention mask: node i attends to node j iff j is an ancestor of i in the draft tree
def build_tree_mask(parent_indices: list[int]) -> list[list[int]]:
    n = len(parent_indices)
    mask = [[0] * n for _ in range(n)]
    for i in range(n):
        curr = i
        while curr != -1:
            mask[i][curr] = 1
            curr = parent_indices[curr]
    return mask

Acceptance criteria

Target: no scenario-correlated errors in the tested workload, no duplicate committed writes, and no routine forced termination. Document traffic patterns, duration, and fault injections. A clean run is evidence—not an unconditional guarantee.

06 / Discuss trade-offsBoundaries & alternatives

Know what each control buys.

Control / PatternBenefitTrade-off

Option 2Contiguous pre-allocated KV buffers (wastes up to 60% HBM due to internal fragmentation).—

Review questions

Failure scenario 1

Failing to rewind the draft model's KV cache alongside the target KV cache causes draft quality to collapse on the next step.

Failure scenario 2

RDMA KV-cache transfer latency exceeding 20 ms negates speculative speedup on short prompts.

Alternatives considered

  • Lookahead decoding (Jacobi iteration) requiring zero draft models.
