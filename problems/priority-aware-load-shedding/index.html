01 / UnderstandFailure & constraints

Clarify what is failing.

Shared Tomcat FIFO queues and priority-blind Envoy circuit breakers caused telemetry requests to saturate all 4,000 threads.

Design objective

Inspect Envoy upstream_rq_pending_overflow and Tomcat active thread metrics.

Requirements

  • Guarantee 99.99% availability for Tier-0 (`/checkout`, `/auth`) even when Tier-3 (`/telemetry`) spikes 15x.
  • Shed excess Tier-2/Tier-3 load at the edge within <1 ms before it consumes backend CPU or DB connections.
  • Avoid static RPS caps that reject low-priority traffic when the cluster has spare capacity.
  • Prevent FIFO queue head-of-line blocking during transient microbursts.

Constraints

  • Backend fleet capacity is 20,000 RPS total across 20 pods (200 worker threads/pod).
  • All endpoints share the same Kubernetes Ingress / Envoy gateway.
  • Telemetry clients retry with exponential backoff only on HTTP 429/503 with Retry-After.
Known failure modes

FIFO head-of-line blocking.

  1. 01Trusted Classification: Edge strips client headers and tags /checkout as Tier-0 and /telemetry as Tier-3.
  2. 02Early Edge Rejection: When adaptive concurrency drops, Tier-3 receives 429 + Retry-After: 30 at Envoy.
  3. 03Priority Admission: Tier-0 bypasses Tier-3 throttling and enters dedicated high-priority pool.
  4. 04SLA Preserved: Checkout and Auth maintain 99.99% success rate despite 35k RPS telemetry flood.
  5. 05Backed-off Clients: Telemetry SDKs back off with jitter, relieving ingress pressure.
Trusted edge tiering + adaptive shedding + isolated bulkheads protect Tier-0 revenue flows under 15x Tier-3 spikes.

The invariants

  • Enforce Tier-3 Semaphore + systemLoadRatio check.

04 / ImplementConfiguration & code

Build the safeguards.

Offload Tier-3 shedding to an edge WAF / CDN rate-limiter or Envoy local_ratelimit filter before heavy JWT/body parsing.

1. Reference implementation

JAVA · Solution
if (tier == 3 && (systemLoadRatio() > 0.75 || !tier3Permits.tryAcquire())) { res.setStatus(429); return; }

2. Harden for scale

Offload Tier-3 shedding to an edge WAF / CDN rate-limiter or Envoy local_ratelimit filter before heavy JWT/body parsing.

YAML · Scale hardening
name: envoy.filters.http.local_ratelimit
typed_config:
  stat_prefix: telemetry_shed

3. Operational controls

Step 1

Place Envoy local_ratelimit early in the HTTP filter chain.

Step 2

Return 429 without invoking ext_authz or body buffering.

Implementation note

Telemetry experiences 429s earlier (at 75% load) to leave 25% headroom for Tier-0.

05 / Verify & observeEvidence & acceptance

Prove the fix works.

Return randomized `Retry-After` headers (e.g., 20-40s) and configure SDKs with full-jitter exponential backoff + max-buffer drop.

  • ↗
    Add random jitter to Retry-After on 429 responses.
  • ↗
    Cap SDK retry attempts at 3 before dropping non-critical telemetry.
JAVA · Verification
res.setHeader("Retry-After", String.valueOf(20 + ThreadLocalRandom.current().nextInt(20)));

Acceptance criteria

Target: no scenario-correlated errors in the tested workload, no duplicate committed writes, and no routine forced termination. Document traffic patterns, duration, and fault injections. A clean run is evidence—not an unconditional guarantee.
