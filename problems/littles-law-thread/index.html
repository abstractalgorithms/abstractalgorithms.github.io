A shared 200-thread Tomcat pool serves 1,000 RPS: 600 RPS of fast /catalog (10 ms) and 400 RPS of /checkout calling a fraud API (50 ms).

By Little's Law (L=λWL = \lambda WL=λW), normal concurrency is $600 \times 0.01 + 400 \times 0.05 = 26$ threads.

STAGE 04 · ENTERPRISE SOLUTIONL6 · SCALE & TRADE-OFFS

Enterprise Solution: Little's Law Bulkheads + Strict Timeouts + Load Shedding.

Why this matters: Operational control: configure bounds, failure handling, and safe production defaults.

Size each dependency's pool via L=λWL = \lambda WL=λW and isolate failure domains:

  • Calculate Pool Size: For 400 RPS /checkout at 50 ms normal (150 ms p99 timeout), L=400×0.10s=40L = 400 \times 0.10\text{s} = 40L=400×0.10s=40 threads (or Semaphore(40)).
  • Bounded Queue (ArrayBlockingQueue(20)) + AbortPolicy: Reject excess /checkout calls immediately with 503 / fallback rather than queuing for seconds.
  • Adaptive Concurrency / Timeout: Enforce a strict 150 ms socket timeout on the fraud client so hung connections release threads fast, leaving 160+ Tomcat threads free for /catalog (6 threads needed).
Bulkhead Thread Pool Topology

Dedicated Bounded Executors Sized via L = λW

1.Little's Law: Concurrency L = Arrival Rate (λ) × Latency (W).

2.Bounded Queue: Small ArrayBlockingQueue(20) absorbs micro-bursts without latency bloat.

3.AbortPolicy: Sheds excess load with 503 instead of starving /catalog.

4.Fast Timeouts: 150 ms fraud timeout caps worst-case thread hold time.

Per-dependency bulkheads sized with Little's Law contain brownouts to the degraded endpoint.

import java.net.http.*;
import java.time.Duration;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicLong;

public class FraudBulkheadClient {
    private final Semaphore bulkhead = new Semaphore(40);
    private final HttpClient http = HttpClient.newBuilder()
            .connectTimeout(Duration.ofMillis(100)).build();
    private final ConcurrentLinkedDeque<Boolean> slowWindow = new ConcurrentLinkedDeque<>();
    private final AtomicLong openUntilNano = new AtomicLong(0);

    public String checkFraud(HttpRequest req) throws Exception {
        if (System.nanoTime() < openUntilNano.get()) {
            throw new RejectedExecutionException("Fraud circuit OPEN");
        }
        if (!bulkhead.tryAcquire()) {
            throw new RejectedExecutionException("Fraud bulkhead FULL (40/40)");
        }
        long start = System.nanoTime();
        boolean slowOrFailed = false;
        try {
            HttpRequest timed = HttpRequest.newBuilder(req, (k, v) -> true)
                    .timeout(Duration.ofMillis(250)).build();
            HttpResponse<String> res = http.send(timed, HttpResponse.BodyHandlers.ofString());
            if (System.nanoTime() - start > 200_000_000L || res.statusCode() >= 500) {
                slowOrFailed = true;
            }
            return res.body();
        } catch (Exception e) {
            slowOrFailed = true;
            throw e;
        } finally {
            bulkhead.release();
            recordOutcome(slowOrFailed);
        }
    }

    private synchronized void recordOutcome(boolean slowOrFailed) {
        slowWindow.addLast(slowOrFailed);
        if (slowWindow.size() > 50) slowWindow.removeFirst();
        if (slowWindow.size() == 50 && slowWindow.stream().filter(b -> b).count() >= 25) {
            openUntilNano.set(System.nanoTime() + 10_000_000_000L); // Open 10s
            slowWindow.clear();
        }
    }
}
