01 / UnderstandFailure & constraints

Clarify what is failing.

Each token requires 320 KB cluster-wide (40 KB/GPU under TP=8); reserving 32,768 tokens per request locks 10.48 GB even for a 200-token prompt.

Design objective

Compute `2 * layers * kv_heads * head_dim * 2 bytes` = 327,680 bytes/token.

Requirements

  • Eliminate internal and external KV cache fragmentation so HBM utilization exceeds 92% for active tokens.
  • Support copy-on-write block sharing for shared system prompts (e.g., 4,096-token RAG prefixes) and parallel sampling (`n=4`).
  • Handle GPU HBM saturation gracefully via deterministic preemption (recompute vs. swap to host RAM) without OOM crashes.
  • Maintain TTFT (Time to First Token) < 250 ms for cached prefixes and ITL (Inter-Token Latency) < 35 ms.

Constraints

  • Model weights (FP16, 140 GB) across TP=8 consume 17.5 GB/GPU; reserve 5 GB/GPU for activations/CUDA graphs, leaving ~57.5 GB/GPU (460 GB total) for KV cache.
  • Host-to-GPU interconnect is PCIe Gen5 x16 (~64 GB/s unidirectional per GPU).
  • Maximum sequence context length is 32,768 tokens.
Known failure modes

Internal fragmentation wastes up to 95% of reserved HBM on short chat prompts.

  1. 01Prefix Lookup & Block Allocation: BlockSpaceManager hashes 16-token chunks; matching prefix blocks increment ref_count without recomputing KV.
  2. 02Dynamic Decode Append: Each decode step appends 1 token into the tail physical block; a new block is allocated only every 16 tokens.
  3. 03Copy-on-Write Forking: If a shared block (`ref_count > 1`) receives a new token, only that tail block is copied to a fresh physical block.
  4. 04LIFO Preemption & Swap: When free GPU blocks drop below watermark, newest running sequences are swapped to CPU RAM or marked for recompute.
  5. 05Unreferenced Prefix Eviction: Completed requests leave blocks cached with ref_count=0 in an LRU list, evicted only when active requests need space.
PagedAttention decouples logical token order from physical GPU memory, enabling prefix sharing and non-OOM preemption.

The invariants

  • Hash (parent_hash, tuple(token_ids)) to identify reusable 16-token prefix blocks.
  • On hit: if ref_count == 0, remove from eviction_lru and increment ref_count.
  • On alloc miss: pop from free_blocks or evict oldest entry from eviction_lru.
03 / Trace the lifecycleKey decisions

Follow the execution path.

Preempt LIFO (newest request) so older requests finish and release all their blocks; recompute short sequences and swap long sequences.

Step 1

LIFO prevents starvation and maximizes request completion rate.

Step 2

Compare PCIe swap time (KV_bytes / 64 GB/s) against prefill compute time (2 * params * tokens / FLOPS).

PYTHON · Lifecycle trace
def choose_preemption_mode(seq_len: int, kv_bytes_per_token_gpu: int = 40960) -> str:
    swap_ms = (seq_len * kv_bytes_per_token_gpu) / (64e9) * 1000
    # H100 TP=8 prefill ~ 12,000 tok/s for 70B FP16
    recompute_ms = (seq_len / 12000.0) * 1000
    return "SWAP" if swap_ms < recompute_ms and seq_len >= 1024 else "RECOMPUTE"
Key trade-off

Swapping consumes host pinned RAM and PCIe bandwidth.

1. Reference implementation

PYTHON · Solution
from collections import OrderedDict
from dataclasses import dataclass

@dataclass
class PhysicalBlock:
    block_id: int
    block_hash: int | None = None
    ref_count: int = 0

class PrefixBlockAllocator:
    def __init__(self, num_blocks: int):
        self.blocks = [PhysicalBlock(i) for i in range(num_blocks)]
        self.free_ids = list(range(num_blocks))
        self.hash_to_id: dict[int, int] = {}
        self.evict_lru: OrderedDict[int, int] = OrderedDict()

    def allocate(self, block_hash: int | None = None) -> PhysicalBlock | None:
        if block_hash is not None and block_hash in self.hash_to_id:
            bid = self.hash_to_id[block_hash]
            blk = self.blocks[bid]
            if blk.ref_count == 0:
                self.evict_lru.pop(bid, None)
            blk.ref_count += 1
            return blk
        if self.free_ids:
            bid = self.free_ids.pop()
        elif self.evict_lru:
            bid, _ = self.evict_lru.popitem(last=False)
            old_hash = self.blocks[bid].block_hash
            if old_hash is not None:
                self.hash_to_id.pop(old_hash, None)
        else:
            return None  # Trigger LIFO preemption
        blk = self.blocks[bid]
        blk.block_hash = block_hash
        blk.ref_count = 1
        if block_hash is not None:
            self.hash_to_id[block_hash] = bid
        return blk

    def free(self, bid: int) -> None:
        blk = self.blocks[bid]
        blk.ref_count -= 1
        if blk.ref_count == 0:
            if blk.block_hash is not None:
                self.evict_lru[bid] = blk.block_hash
            else:
                self.free_ids.append(bid)

3. Operational controls

Step 1

Split 32k-token prefills into 2,048-token chunks piggybacked onto decode batches.

Step 2

Cap total batched tokens per iteration to bound step latency under 35 ms.

Implementation note

Using 64-bit hashes risks rare collisions; production engines (vLLM/SGLang) store the token tuple or 128-bit xxhash to verify exact match.

PYTHON · Verification
def write_token_cow(seq_blocks: list[PhysicalBlock], allocator: PrefixBlockAllocator) -> PhysicalBlock:
    tail = seq_blocks[-1]
    if tail.ref_count > 1:
        new_blk = allocator.allocate(block_hash=None)
        # GPU kernel copies existing tokens from tail.block_id -> new_blk.block_id
        allocator.free(tail.block_id)
        seq_blocks[-1] = new_blk
        return new_blk
    return tail

Acceptance criteria

Target: no scenario-correlated errors in the tested workload, no duplicate committed writes, and no routine forced termination. Document traffic patterns, duration, and fault injections. A clean run is evidence—not an unconditional guarantee.

Review questions

Failure scenario 1

Running a single 32k prefill unchunked stalls all 500 decode streams for >2 seconds.

Failure scenario 2

Alternatives considered

  • Eagerly copy only the last partial block at fork time.
