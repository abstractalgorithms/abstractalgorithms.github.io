The idea to keep with you

To keep the architecture evolvable without sacrificing reliability, sync document ACL changes independently from re-embedding chunks so permission revocations take effect in seconds without recomputing 150M vectors.

TL;DR30-second simplified summary
▾

At 10M documents (~150M 512-token chunks), re-embedding an entire folder just because one user lost Google Drive access would crush GPU pipelines. Decouple Chunk Vector Storage from ACL Metadata (storing allowed_principals in a fast-update payload/bitmap index synced via CDC webhooks).

On query, the gateway resolves the user's transitive Okta/AD group memberships (cached 60s), executes ACL-prefiltered HNSW + BM25 search across sharded Qdrant/Elasticsearch nodes, merges Top-50 via RRF, and reranks to Top-5 with a GPU Cross-Encoder.

Hybrid RAG: RRF Reranking & Document-Level ACL Filtering
Hybrid RAG combines dense HNSW vector search with sparse BM25 lexical search via Reciprocal Rank Fusion (RRF), enforces document-level ACLs via pre-filtered Roaring Bitmaps, and reranks Top-50 -> Top-5 with a Cross-Encoder.
RAG Retrieval Pipelines
Production RAG retrieval combines semantic chunking, hybrid dense (HNSW) + sparse (BM25/SPLADE) search, Reciprocal Rank Fusion (RRF), metadata pre-filtering, and cross-encoder reranking to deliver high-precision context to LLMs.
Vector Databases & RAG
Retrieval-Augmented Generation (RAG) grounds LLM outputs by indexing domain documents as dense/sparse vectors and retrieving top-k relevant chunks at query time via approximate nearest neighbor (ANN) indexes like HNSW.

def search_enterprise_rag(user_principals: set[str], query: str, dense_idx, bm25_idx, reranker) -> list[dict]:
    if not user_principals:
        raise PermissionError('Fail closed: user_principals cannot be empty')
    dense_hits = dense_idx.search_prefiltered(query, principals=user_principals, limit=50)
    sparse_hits = bm25_idx.search_prefiltered(query, principals=user_principals, limit=50)
    fused = reciprocal_rank_fusion(dense_hits, sparse_hits, top_n=50)
    return reranker.rerank(query, [doc_id for doc_id, _ in fused], top_k=5)
STAGE 03 · SAFE IMPLEMENTATION

ACL-Scoped Hybrid Retrieval Guard

1.Fail-Closed First: An empty principal set never falls back to 'public'—it raises PermissionError immediately.

2.Defense in Depth: Re-verify document ACLs on the final Top-5 chunk metadata fetch before returning to the LLM.

3.Deterministic RRF: Combine dense and sparse ranks deterministically before GPU reranking.

Failing closed on empty principals and double-checking Top-5 ACLs enforces zero unauthorized leakage.
