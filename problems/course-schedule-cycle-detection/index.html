01 / CONTRACT & SCOPE3 MIN

Define the problem & constraints.

A valid schedule exists if and only if the directed graph formed by edges (prereq -> course) is a Directed Acyclic Graph (DAG).

SAY THIS

Use iterative Kahn's BFS with an in-degree array for fast cycle detection and topological ordering, and fall back to iterative 3-color DFS only when you need to extract the exact cycle path for diagnostics.

Requirements

  • Verify whether the directed prerequisite graph is a DAG and return a valid topological ordering of all V nodes in O(V + E) time.
  • Handle disconnected components, isolated nodes with zero prerequisites, and duplicate prerequisite edges without double-counting in-degrees.
  • Guarantee zero StackOverflowError / RecursionError on linear chains of depth 100,000 by avoiding unbounded OS thread recursion.
  • Extract and return the exact minimal cycle path (e.g., [C12 -> C45 -> C89 -> C12]) when a dependency cycle blocks scheduling.

Constraints

  • 1 <= numCourses <= 100,000 and 0 <= prerequisites.length <= 500,000.
  • P99 validation latency must stay under 40 ms within a 64 MB per-request heap budget.
  • All application code must be implemented in Python 3 using standard library structures only.

PYTHON / course-schedule-cycle-detection.py
from collections import deque

def solve_course_schedule(num_courses: int, prerequisites: list[list[int]]) -> tuple[bool, list[int], list[int]]:
    adj: list[list[int]] = [[] for _ in range(num_courses)]
    in_degree = [0] * num_courses
    for course, prereq in prerequisites:
        adj[prereq].append(course)
        in_degree[course] += 1

    queue = deque(i for i in range(num_courses) if in_degree[i] == 0)
    order: list[int] = []
    while queue:
        u = queue.popleft()
        order.append(u)
        for v in adj[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)

    if len(order) == num_courses:
        return True, order, []

    # Iterative 3-color DFS for cycle witness
    state = [0] * num_courses  # 0=unvisited, 1=visiting, 2=visited
    parent = [-1] * num_courses
    for start in range(num_courses):
        if state[start] != 0 or in_degree[start] == 0:
            continue
        stack: list[tuple[int, int]] = [(start, 0)]
        state[start] = 1
        while stack:
            u, idx = stack[-1]
            if idx < len(adj[u]):
                stack[-1] = (u, idx + 1)
                v = adj[u][idx]
                if state[v] == 0:
                    state[v] = 1
                    parent[v] = u
                    stack.append((v, 0))
                elif state[v] == 1:
                    cycle = [v]
                    cur = u
                    while cur != v:
                        cycle.append(cur)
                        cur = parent[cur]
                    cycle.append(v)
                    cycle.reverse()
                    return False, [], cycle
            else:
                state[u] = 2
                stack.pop()
    return False, [], []
04 / EDGE CASES & LIMITS4 MIN

Complexity & boundary traps.

Heap-allocated stacks handle 100k-deep chains cleanly; for high-frequency incremental edge insertions, switch to Pearce-Kelly dynamic topological ordering.

Unbounded recursive DFS hitting C-stack limits (~8 MB) or Python's 1,000-frame limit.

05 / TRADE-OFFS & FOLLOW-UPS5 MIN

Alternatives & extensions.

Kahn's BFS is superior for level-by-level parallel dispatch, whereas 3-color DFS is required when extracting a clean cycle witness.

ApproachTimeSpaceTrade-off
Alternative 1——PriorityQueue-backed Kahn's when deterministic tie-breaking by course ID is required.
Trade-off 1——Wave-based Kahn's exposes maximum concurrency per step without changing O(V + E) asymptotic complexity.
Trade-off 2——Lexicographically smallest schedule requires replacing deque with heapq (O((V + E) log V)).
Extend the scheduler to compute the minimum semesters (longest path in a DAG) when each course has a duration weight.

Once Kahn's produces a topological order, relax earliest-completion times dp[v] = max(dp[v], dp[u] + duration[v]) in a single O(V + E) sweep.
