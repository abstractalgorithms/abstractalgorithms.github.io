Stage 1 — How the Router Network Works

  • The core of an MoE layer is the router (or gating network).
  • When a token embedding enters an MoE layer, it first passes through this router.
  • The router is typically a small neural network (e.g., a simple feed-forward network with a softmax layer) that takes the token's representation and outputs a score or probability distribution over all available experts.
  • Based on these scores, the router selects the top-K experts (commonly K=1 or K=2) for that specific token.

Stage 2 — Load Balancing & Performance Considerations

  • A key challenge in MoE routing is ensuring that experts are utilized evenly.
  • If some experts receive disproportionately more tokens, they become bottlenecks, diminishing the performance gains.
  • Modern MoE architectures often incorporate a load balancing loss during training.
  • This loss encourages the router to distribute tokens more uniformly across experts, preventing "expert collapse" where only a few experts are ever chosen.
